## 摘要
现代图像分类模型在单一任务特定数据集上训练时表现出色，但常常难以跨领域和难度水平进行泛化。我们提出ARMDIL，一种用于多领域图像分类的自适应路由器（Adaptive Router for Multi-Domain Image classification with LLMs）。ARMDIL是一个集成框架，使用多模态大语言模型（MLLM）代理将每张图像动态路由到最合适的视觉骨干网络。我们的异构集成采用卷积神经网络（ResNets）、自监督表示学习器（SSL）和视觉-语言模型（VLMs），每个都在由多个具有不同分布和特征的数据集构建的统一标签空间上训练。实证评估阐明了每种架构在不同视觉领域中的独特能力和脆弱性。关键的是，我们表明ARMDIL有效地处理这些权衡，与专门的基于训练的路由器相比具有竞争力。此外，它通过简单的提示修改允许整合新信息，从而大幅提高适应性，同时通过自然语言推理轨迹增强可解释性。这些跨数据集图像分类的进展为更可靠的通用视觉系统（如AI助手和自主机器人）铺平了道路。

## Abstract
Modern image classification models excel when trained on single task-specific datasets but often struggle to generalize across domains and difficulty levels. We propose ARMDIL, an Adaptive Router for Multi-Domain Image classification with LLMs. ARMDIL is an ensemble that uses a multimodal large language model (MLLM) agent to dynamically route each image to the most suitable vision backbone. Our diverse ensemble employs convolutional neural networks (ResNets), self-supervised representation learners (SSL), and vision-language models (VLMs), each trained on a unified label space constructed from multiple image datasets with differing distributions and characteristics. Empirical evaluations illuminate the distinct capabilities and vulnerabilities of each architecture across disparate visual domains. Crucially, we show that ARMDIL effectively navigates these trade-offs, performing competitively with specialized training-based routers. Furthermore, it drastically improves adaptability by allowing new information to be integrated via simple prompt modifications, while enhancing interpretability through natural language reasoning traces. These advances in cross-dataset image classification pave the way for more reliable general-purpose vision systems such as AI assistants and autonomous robots.

## 2. 论文提出的方法论

### 2.1 总体框架：ARMDIL

- ARMDIL = **A**daptive **R**outer for **M**ulti-**D**omain **I**mage classification with **L**LMs。
- 核心思想：将多个异构视觉骨干（ResNet、SSL、VLM）作为"专家工具"，由MLLM代理对每张输入图像进行动态路由，选择最优专家完成分类。

### 2.2 统一标签空间与跨域数据构建

- 为保证路由错误时仍能输出有效预测，所有专家共享统一的**N=38类**标签空间，由四个数据集合并而来：
  - **CIFAR10**（10类，自然物体/动物/车辆，代表"GENERAL"域）
  - **FER2013**（7类情感人脸，代表"FACIAL"域）
  - **EuroSAT**（10类卫星地物，代表"GEOGRAPHIC"域）
  - **OrganAMNIST / O-MNIST**（11类人体器官医学图像，代表"MEDICAL"域）

### 2.3 异构专家训练

- 采用**domain-skewed sampling**策略（表1）：每个训练分布将某一目标域的比例设为70%，其余各域各为10%，从而迫使网络偏向该目标域，成为该域的"专家"；同时训练一个均匀分布（25%×4）的平衡模型作为基线。
- 三类专家架构：
  - **ResNet-50**：ImageNet预训练，擅长局部纹理/边缘，适合医学图像。
  - **SSL（DINOv2 ViT-L/14、DINOv3 ViT-L/16）**：自监督预训练，表征鲁棒，适合人脸等复杂域。
  - **VLM（OpenCLIP ViT-L/14，LAION-2B预训练）**：加入LoRA适配器冻结视觉编码器训练线性分类头，适合场景级语义（如卫星图像）。
- 训练细节（附录B）：AdamW优化器、focal + 加权类别平衡交叉熵损失、混合精度、100 epoch上限、早停（patience=3）、学习率先线性warmup 5 epoch到1e-4再余弦退火50 epoch。

### 2.4 MLLM路由机制

- 使用的模型：**Gemma-4-12B**（Unsloth UD-Q5量化版），可本地部署。
- 输入：原始图像 + 图像质量统计数据（blur、brightness、contrast、noise，如图3）。
- 输出：五个域别名之一——`GENERAL`、`FACIAL`、`GEOGRAPHIC`、`MEDICAL`、`UNSURE`（图2的system prompt）。
- 路由决策：采用**Chain-of-Thought（CoT）推理**，生成自然语言推理轨迹，提高准确率和可解释性。
- 兜底机制：`UNSURE`域的图像被路由到整体验证准确率最高的模型（平衡DINOv3）。
- 相比传统方法：
  - 相比多数投票（MV）：无需让所有模型处理所有输入，节省计算。
  - 相比NN-Router：无需训练路由网络，通过修改提示即可扩展或更新域定义。

- **统一标签空间限制了类别粒度**：虽然共享标签空间是为容错性服务，但38个类别过于粗糙，与真实应用（如ImageNet-1K、COCO等数千类别）相去甚远。在这种简化设置下，即使路由错误，专家模型之间的标签重叠也较多，掩盖了实际域差异带来的冲突。真实场景中不同域的标签空间往往完全不同，如何设计更灵活的输出映射仍是一个未被解决的问题。

## 9. 未来工作与改进方向

- **优化路由prompt与UNSURE策略**：针对EuroSAT域误判率高的问题，作者可以设计更明确的指令（如提示“卫星图像通常具有规则几何纹理”），或引入一个域置信度阈值，将低于阈值的样本直接交给平衡专家，从而减少UNSURE的滥用。
- **探索更强大的路由模型**：在资源允许的前提下，尝试更大的LLM（如GPT-4、Gemini）或对Gemma进行轻量微调（LoRA），使其更准确地将视觉特征映射到域标签。也可以考虑将图像质量统计与视觉token结合，构造更丰富的路由输入。
- **扩展到更多域与真实场景**：在更多视觉域（如文本渲染、3D渲染、水下图像、医学内镜）和更大数据集上验证ARMDIL的泛化性；同时设计处理重叠标签空间（如“猫”同时出现在自然图像与人脸域）的机制。
- **端到端可微路由**：将MLLM的域判断输出转化为可微的权重，与专家预测进行软融合，从而允许通过反向传播对路由部分进行联合微调，进一步提升整体精度。
- **成本感知的客户化配置**：提供“快速模式”（无CoT、直接输出域标签）和“精确模式”（CoT+自一致性）两种路由选项，供用户根据延迟和准确率要求灵活选择。

## 10. 总结评价

总体而言，ARMDIL是一项有洞察力的工作，它巧妙地将多模态大语言模型从单纯的特征提取器或分类器角色，提升为跨域视觉系统的智能调度者。通过“零样本路由+异构专家”的组合，论文在多个标准基准上获得了比单模型或传统集成更优的性能，并显著提升了系统的可解释性和可扩展性。尽管在当前实验设置下，其性能与NN-Router仍有微小差距，但考虑到它完全不需要训练路由网络，且能通过自然语言交互解释决策，这种方法的前景十分诱人。

该论文的最大价值不在于超越几个百分点的准确率，而在于提出了一种新的系统设计范式：未来通用视觉智能不一定依赖于单个全能模型，而可能是一个由MLLM驱动的“专家市场”，通过语言交互动态调配各种专用模型。这种观点对AI助手、具身智能、多模态应用等方向都有启发意义。

不过，要使这一范式真正落地，仍需克服路由可靠性、推理成本和标签空间灵活性等关键挑战。特别是EuroSAT域的低路由准确率，反映出MLLM对某些视觉“纹理”的敏感性不足。这也提示我们，简单的语言指令可能不足以全面描述视觉域的本质特征，需要结合更丰富的多模态线索（如频域统计、局部特征分布）来改进路由。
