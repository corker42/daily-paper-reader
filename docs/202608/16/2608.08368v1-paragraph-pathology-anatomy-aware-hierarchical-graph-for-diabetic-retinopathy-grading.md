## 摘要
糖尿病视网膜病变（DR）仍是全球工作年龄成年人视力丧失的主要原因，因此可靠的严重程度分级在临床上具有重要意义。尽管深度模型性能强劲，但大多数方法将DR分级视为图像级分类，并未显式建模临床依据，如病变类型和空间关系。本文提出PARAGraph，一种用于DR分级的病理-解剖感知层次图框架。PARAGraph将每张图像表示为三级层次图，包含病变级节点、中间类别和区域节点，以及全局解剖和语义节点。为了将医学先验融入节点，我们构建了以视盘-中心凹为锚点的坐标系，提供尺度与旋转归一化的视网膜参考系统。在该坐标系内，病变节点编码了类别、归一化面积和解剖坐标。为减轻病变分割噪声，PARAGraph采用双融合策略，将全局视觉上下文引入图语义节点和决策级预测分支，在病变证据不可靠时提升鲁棒性。在Messidor-2、APTOS和DDR上的大量实验表明，PARAGraph在DR分级性能上一致优于现有最先进方法。可解释性和鲁棒性分析进一步证明其预测具有临床依据，与病变证据紧密相关，并对病变分割噪声具有鲁棒性。

## Abstract
Diabetic retinopathy (DR) remains a leading cause of vision loss among working-age adults worldwide, making reliable severity grading clinically important. Despite strong performance, most deep models formulate DR grading as image-level classification and do not explicitly model clinically grounded evidence, such as lesion types and spatial relations. In this paper, we propose PARAGraph, a Pathology-Anatomy-Aware Hierarchical Graph framework for DR grading. PARAGraph represents each image as a three-level hierarchical graph with lesion-level nodes, intermediate category and region nodes, and global anatomical and semantic nodes. To incorporate medical priors into nodes, we construct an optic disc-fovea-anchored coordinate frame that provides a scale- and rotation-normalized retinal reference system. Within this frame, lesion nodes are encoded with category, normalized area, and anatomical coordinates. To mitigate noisy lesion segmentation, PARAGraph uses a dual-fusion strategy that introduces global visual context into a graph semantic node and a decision-level prediction branch, improving robustness when lesion evidence is unreliable. Extensive experiments on Messidor-2, APTOS, and DDR show that PARAGraph achieves consistent DR grading performance over state-of-the-art methods. Interpretability and robustness analyses further demonstrate that its predictions are clinically grounded, closely associated with lesion evidence and robust to lesion segmentation noise.

## 2. 论文提出的方法论

### 2.1 核心思想
PARAGraph将每张眼底图像表示为一张**图像内的异构图**，节点分为三级：
- **病变级节点**：单个检测到的病变，融合视觉特征与医学先验（类别、归一化面积、解剖坐标）。
- **中间级节点**：包括类别节点（同一病变类别的聚合）和区域节点（空间聚类后的聚合），用于捕获类别语义和空间分布模式。
- **全局级节点**：包括解剖节点（视盘区域特征）和图像级语义节点（全局图像上下文）。

### 2.2 关键技术细节

**（1）视盘-中心凹锚定的解剖坐标系（OD-Anchored Anatomical Coordinate System）**
- 以视盘中心为原点，视盘中心到中心凹中心方向为x轴正方向。
- 空间坐标用视盘直径归一化，实现尺度不变；用极坐标描述（径向距离、正弦/余弦角度）实现旋转不变。
- 对于图像块位置p，计算解剖描述子：
  ```
  e(p) = [ r/d_OD, sinθ, cosθ ]
  ```
  其中r为p到视盘中心的距离，θ为相对视盘-中心凹轴的角度。
- 将该描述子通过MLP映射为位置偏置b(p)，加到视觉主干对应patch embedding上：
  ```
  z̃_p = z_p + b(p)
  ```
  使视觉编码器能感知解剖位置。

**（2）医学先验增强的层次图（Prior-Knowledge-Enhanced Hierarchical Graph）**
- 病变节点特征由四部分拼接：
  ```
  f_lesion = Concat(f_vis, f_coord, f_area, f_cls)
  ```
  - f_vis：从解剖感知编码器采样得到病变区域的视觉特征；
  - f_coord：病变在解剖坐标系中的归一化位置投影；
  - f_area：病变面积除以视盘直径平方（尺度归一化面积）的投影；
  - f_cls：病变类别（如微动脉瘤、出血、硬性渗出、软性渗出）的投影。
- 类别节点：对同一类别内所有病变的视觉特征做自注意力聚合，自适应加权，抑制噪声。
- 区域节点：基于病变坐标做K-means聚类，对每个簇内病变做注意力池化，捕获跨类别的空间聚集模式。
- 解剖节点：提取视盘区域的多尺度视觉特征，作为分割无关的稳定锚点。
- 图像级语义节点：由全局特征F通过MLP投影得到，参与消息传递，补充分割病变之外的弥漫性异常信息。

**（3）双阶段全局融合（Global Context Fusion）**
- **早期融合**：将图像级语义节点作为图节点，在消息传递过程中注入全局上下文，影响病变级表示。
- **晚期融合**：独立全局分支Head_s(F)产生logits ℓ_s，与图分支logits ℓ_g相加，再softmax获得最终预测：
  ```
  ℓ = ℓ_g + ℓ_s,  p̂ = softmax(ℓ)
  ```
  融合两种预测路径，增强鲁棒性。

**（4）置信度门控图推理（Confidence-Gated Graph Reasoning）**
- 每个节点赋予置信度s_j（病变节点来自分割模型预测分数；中间节点为其关联病变平均置信度；解剖节点为相关类别节点置信度聚合；语义节点置信度恒为1）。
- 消息传递时，用门控函数g(s)=σ(λs+β)对两个端点置信度进行加权，抑制低置信度节点传播噪声。
- 使用图注意力网络（GAT）进行L层消息传递，最后经图级读出得到图分支预测。

## 6. 论文的主要结论与发现

- **性能优势**：PARAGraph在三个数据集上均取得最高QWK（Messidor-2: 88.47，APTOS: 93.85，DDR: 88.62），比第二名分别高+0.65、+2.32、+1.26；同时获得最高的ACC和大部分最高的SPE。
- **结构有效性**：层次图（尤其添加类别和区域节点）带来显著增益；医学先验融合（位置、面积、类别）是最大贡献组件（移除后QWK下降0.88）。
- **全局融合必要性**：移除整个全局通路导致QWK下降1.82，早期融合贡献大于晚期融合，两者互补。
- **临床可解释性**：预测与真实病变证据紧密相关；微动脉瘤主要驱动Grade 1，出血主要驱动Grade 2–3；图像级节点在Grade 0和Grade 4（健康与增殖期）占主导，中间非增殖期更依赖病变节点。
- **鲁棒性**：对漏检病变性能平滑下降；对病变误分类和假阳性不敏感（QWK保持约88），说明置信度门控有效抑制了分割噪声。
- **特征空间**：t-SNE显示PARAGraph的嵌入更紧凑、分级结构更清晰，健康、非增殖、增殖期分离明显。

## 7. 优点

1. **临床先验显式建模**：将病变类型、面积、位置以医学坐标系编码进图节点，而非仅依赖隐式特征，提升了预测的临床可追溯性。
2. **层次化图结构设计巧妙**：三类节点（病变、类别/区域、全局）能同时捕获细粒度病变、类别语义和空间聚集模式，信息互补。
3. **解剖坐标系具备尺度/旋转不变性**：以视盘为中心、视盘直径归一化，提高了跨数据集和成像条件的迁移能力。
4. **双融合机制兼顾可解释性与鲁棒性**：早期融合注入全局上下文，晚期融合提供独立预测路径，使模型在分割不佳时不会崩溃。
5. **置信度门控创新**：将分割置信度引入图消息传递，有效抑制低质量检测节点的影响，是提高鲁棒性的关键设计。
6. **实验分析全面**：除性能指标外，还系统评估了忠实度、归因、噪声鲁棒性和特征可视化，证据链完整。

## 8. 不足与局限

1. **依赖预训练分割模型**：虽然门控和融合减轻了噪声影响，但图结构仍建立在分割输出之上；分割模型未覆盖的病变类型（如新生血管、IRMA）会被忽略，影响增殖期DR分级。
2. **消融与鲁棒性实验仅在单一数据集（DDR）上进行**：未在Messidor-2和APTOS上验证各组件的普适性，结论可能存在数据集偏差。
3. **鲁棒性测试使用人为注入噪声**：模拟的漏检/误分类/假阳性场景与真实分割错误分布可能差异较大，真实世界的性能退化程度需进一步验证。
4. **未报告统计显著性检验**：虽然给出了均值±标准差，但未说明是否对主要指标进行显著性测试（如配对t检验），无法确定差异是否统计显著。
5. **计算开销与可复现细节不足**：未公开模型参数量、训练时间、内存占用、超参数搜索范围等，单张GPU训练但无训练时长说明，复现成本不透明。
6. **临床部署验证缺失**：实验均为离线公共数据集，未涉及真实临床工作流、跨设备/跨人群泛化或时间与资源约束下的表现。
7. **分级极端依赖全局语义的隐患**：对Grade 0和Grade 4依赖图像级节点，如果该分支过强，可能退化为普通图像分类器，削弱病变解释能力；论文未详细讨论该风险平衡机制。
