## 摘要
基础模型可通过工具调用框架充当临床智能体。然而，传统医学基准评估的是对预选证据的推理能力，而非在临床记录与纵向影像中主动搜寻证据的能力。我们提出 CASE：一系列角色专用的证据搜寻临床智能体（Clinical Agents for Seeking Evidence），并配套工具调用框架以及面向紧凑型视觉-语言策略模型的智能体后训练框架。我们进一步提出一个基于英国生物样本库（UK Biobank）构建的纵向多模态基准，包含 50,401 个临床问题，这些问题源自 4,739 名参与者的真实世界 ICD-10 编码诊断。每个问题都关联一个患者专属环境，其中包含临床背景信息以及基线与随访访视的多序列 MRI；智能体在其中自主选择要检查和比较的访视、器官、模态、切片及专科工具。监督微调从 14,734 条前沿模型的交互轨迹中迁移证据搜寻工作流，随后在学习者自身与环境的交互上进行智能体强化学习。特权同策略自蒸馏与基于评分规则的 LLM 反馈可精炼从证据到结论的推理，而不预设工具使用序列。实验表明，CASE 超越了问答模仿，转向可迁移的探究策略，增强了基于证据的纵向推理能力。在匹配的评估条件下，我们基于 Qwen3-VL-8B 的智能体在答案准确率上相较 GPT-5.4 和 Claude Opus 4.8 分别取得超过 16% 和 10% 的相对提升。代码将发布于 https://github.com/VinyehShaw/CASE。

## Abstract
Foundation models can serve as clinical agents through tool-use harnesses. However, conventional medical benchmarks assess reasoning over preselected evidence rather than the ability to seek it across clinical records and longitudinal imaging. We propose CASE: a series of role-specific Clinical Agents for Seeking Evidence, together with a tool-use harness and an agentic post-training framework for compact vision-language policy models. We further introduce a longitudinal multimodal benchmark built on UK Biobank, comprising 50,401 clinical questions derived from real-world ICD-10-coded diagnoses of 4,739 participants. Each question links to a patient-specific environment containing clinical context and multi-sequence MRI from baseline and follow-up visits, where agents autonomously select which visits, organs, modalities, slices, and specialist tools to inspect and compare. Supervised fine-tuning transfers evidence-seeking workflows from 14,734 frontier-model interaction trajectories, followed by agentic reinforcement learning on the learner's own environment interactions. Privileged on-policy self-distillation and rubric-based LLM feedback refine evidence-to-conclusion reasoning without prescribing tool sequences. Experiments show that CASE moves beyond question-answer imitation toward transferable investigation policies, strengthening evidence-grounded longitudinal reasoning. Under matched evaluation conditions, our Qwen3-VL-8B based agent achieves over 16% and 10% relative improvements in answer accuracy over GPT-5.4 and Claude Opus 4.8. Code will be available at https://github.com/VinyehShaw/CASE.

## 2. 方法论

- **总体流程**：两阶段训练。
  - **阶段一 RSFT（拒绝采样微调）**：用 Qwen3.8-Max 在 LangGraph 环境记录角色条件轨迹，共 147,434 条；筛选条件为至少 1 次工具调用且存在可解析的 Phase-4 insight，Kimi K2.6 按四标准打分 ≥ 0.4，保留约 14 万条演示；在 Qwen3-VL-8B-Instruct 上做混合角色 SFT，仅在 assistant 位置计算 next-token 交叉熵。
  - **阶段二 Agentic RL**：策略在自身环境交互上优化，不使用真实答案作为上下文监督。
- **角色与工具**：一个共享策略通过角色提示实例化三种智能体。
  - **Radiologist**：`list_available_images`、`view_image`、`compare_visits`，预算 6 次调用；
  - **Anatomist**：`vista3d_segment`、`vista3d_compare_stations`、`vista3d_compare_visits`，预算 4 次调用；
  - **Consultant**：上述 6 个工具加 `list_available_reports`、`get_report`、`recall_skills`、`write_skill`，预算 12 次调用。
- **通用交互循环**：助手每轮发出工具请求或结束调查；工具返回文本与图像进入上下文；最终响应包含五个阶段：P1 规划、P2 多源回顾、P3 跨访视比较/验证、P4 关键洞察、P5 答案。P1–P5 是推理结构，不规定工具顺序。
- **可重放证据环境**：每个参与者仅离线预计算两项源产物——Vista3D 对全身 Dixon MRI 的六站分割掩码，以及 MedGemma-27B 报告对象。RL 用 mock tools 按 `(participant, tool, arguments)` 键回放缓存观察，工具选择、参数、检索顺序与停止完全由策略生成。
- **GRPO 基础**：每个 prompt 采样 G=8 条轨迹，组相对优势 `Aj = sg[(Rj - R̄)/(sd(R)+ε)]`，所有 assistant token 共享该轨迹级优势，工具观察不携带梯度目标。
- **OPSD（特权同策略自蒸馏）**：
  - 对每条 rollout，用同一冻结快照分别前向计算**普通视图** `q = π(v | g)` 与**答案特权视图** `p = π(v | g+ z*)`，其中 `z*` 提供参考答案、可解析选项文本与可选记录 insight；
  - 在估计的 Phase-4 区域计算反向 KL，实现上只保留学生 top-128 token 加一个残差桶，共 129 个事件；
  - 形式为 `D_CKL = (1/Cj) Σ_{t∈Ij} [Σ_{v∈S} q log(q/p) + q⊥ log(q⊥/p⊥)]`；
  - 该分数以 **detached** 方式作为轨迹级奖励惩罚，系数 2.0，在组归一化前进入回报，可重排整条轨迹；
  - 自教师随策略更新刷新，而非固定外部教师。
- **RLAIF 与链接奖励**：
  - Kimi K2.6 按固定 rubric 给 Phase-4 insight 打分 `sj ∈ [0,1]`：证据识别 0.3、逻辑推理 0.3、答案支持 0.2、完整性 0.2；
  - 组内 top-2 洞察置 `bj=1`，链接奖励 `Lj = bj[0.5cj - 0.3(1-cj)]`，其中 `cj` 为答案完全正确；
  - 复合回报：`Bj = r_ans + 0.01 r_fmt + 0.6 sj + Lj`，`Rn,j = sg[Bj - 2 D_CKL]`；
  - `r_ans` 在答案完全匹配时为 +1，错误为 -1，无法解析为 -2。
- **策略优化**：标准 PPO 式裁剪代理目标，裁剪半径 η=0.2，外加 0.05 的冻结 SFT 参考 KL 惩罚；优化器更新视觉编码器、视觉 merger 与语言解码器全部参数。
- **OPSD 的动机**：中期 RL 策略易陷入重复陈述、无法收敛到结论；答案特权视图在固定合成前缀下将概率质量从"继续复述"转向"推进或终止"，从而在不指定内容的前提下抑制重复。

## 3. 实验设计

- **Benchmark**：基于 UK Biobank 构建，50,401 道题，来自 4,739 名参与者；其中 4,850 道 held-out 题来自 455 名参与者。问题源自真实 ICD-10 诊断，覆盖 7 个临床家族、6 个临床域、10 个 task–format 层。
- **题型分布**：二选 17,502（34.7%）、单选 19,790（39.3%）、多选 13,109（26.0%）。
- **影像环境**：每个问题关联患者专属环境，包含基线与随访多序列 MRI（中位间隔 2.26 年），覆盖 5 个器官区域（心、脑、胰腺、肝、全身）与 7 个 sub-modality；大多数参与者有 2–3 个器官组。工具可返回 MRI 视图、Vista3D 测量与叠加、MedGemma 报告。
- **评测协议**：
  - 主指标为 **first-pass exact answer-set accuracy**，多选题要求完全集合相等；
  - 报告 Micro（题目等权）与 Macro（十层等权）；
  - 参与者跨划分互斥；
  - 10,000 次配对 participant-cluster bootstrap 给出 95% 区间；
  - 固定外部 judge 提供 insight 质量分，与准确率互补。

- **对比方法（Baselines）**：
  - **无工具闭卷基线**：Qwen3-VL-8B-Instruct、GPT-5.x、Claude Opus 4.x、Gemini 3 Pro、Qwen3.8-Max 等直接读题作答；
  - **前沿模型 + 全工具**：将 CASE 工具集暴露给上述前沿模型，使用统一 system prompt 与预算，构成"同环境下的强教师参照"；
  - **教师轨迹回放上界**：直接以 RSFT 阶段 Qwen3.8-Max 记录的成功轨迹作为参考，衡量学生离教师分布的距离；
  - **消融变体**：RSFT-only、RSFT + GRPO（无 OPSD、无 RLAIF）、RSFT + GRPO + OPSD、RSFT + GRPO + RLAIF、完整两阶段。
- **实现细节**：
  - 策略与参考模型均为 Qwen3-VL-8B-Instruct；
  - 阶段一使用约 14 万条角色混合演示，学习率与 epoch 数按常规 SFT 设置；
  - 阶段二每 prompt 采样 G=8 条轨迹，训练 prompt 覆盖全部 10 个 task–format 层；
  - OPSD 特权视图的 `z*` 仅在训练时可用，评测时不提供任何答案信息；
  - 外部 judge（Kimi K2.6）与人工抽样一致性通过 Kappa 检验报告，用于支撑 insight 分的可信度。

## 4. 主要结果

- **主结果**：
  - 完整 CASE（8B）在 held-out 上取得显著高于同尺寸闭卷基线的 Micro/Macro 准确率，且在多选题（要求集合完全匹配）上相对提升最大，说明"证据搜寻"收益主要体现在需要跨访视整合的题目上。
  - 与前沿模型在**同工具、同预算**条件下对比，CASE 在 Micro 与 Macro 上均不劣于甚至反超，验证"紧凑模型 + 可训练调查策略"可以部分替代参数规模带来的先验优势。
  - 无工具前沿模型尽管语言先验强，但在需跨访视比较、需调用分割/定量工具的题目上大幅落后，佐证纵向证据搜寻是独立能力维度而非语言能力延伸。
- **分层结果**：
  - 按 7 个临床家族、6 个临床域、10 个 task–format 层报告，Macro 与 Micro 的差距揭示模型在不同层级上表现不均衡；
  - 二选与单选类题型接近饱和，多选与跨访视比较类仍是主要误差来源。
- **统计显著性**：10,000 次 participant-cluster bootstrap 的 95% 区间在多数组间对比中不跨零，说明提升不是由少数参与者或单层题目驱动。

## 5. 消融与分析

- **两阶段必要性**：
  - 仅 RSFT 可超过闭卷基线，但受限于对教师动作的模仿，在教师未覆盖的状态上脆弱；
  - 加入 Agentic RL 后进一步提升，说明策略在自身上采样分布上获得了超越演示分布的调查行为。
- **OPSD 的作用**：
  - 去掉 OPSD 时，RL 训练中频繁出现"重复陈述—不收敛到结论"的退化模式，Phase-4 区域熵下降缓慢、轨迹长度膨胀；
  - 加入 OPSD 后，答案特权视图把概率质量从"继续复述"推向"推进或终止"，在不指定具体内容的前提下压缩无效循环，同时保留探索；
  - 由于自教师随策略刷新，OPSD 惩罚在训练后期仍能提供有效梯度，而非快速饱和。
- **RLAIF 与链接奖励的作用**：
  - 仅用答案奖励时，模型可能通过"猜答案"获得回报，证据质量不升反降；
  - 链接奖励 `Lj` 使"高质量 insight 且答案正确"获得额外增益，同时惩罚"高质量 insight 但答案错误"，促使 insight 与最终答案对齐；
  - 组内 top-2 的稀疏设置抑制了 judge 分数被普遍刷高。
- **工具使用行为分析**：
  - 报告各角色的平均调用次数、调用序列模式与预算使用率，观察策略是否学会"先全局筛查再局部放大"；
  - 对比 RL 前后工具调用分布，量化从"教师常见动作"向"任务自适应动作"的迁移；
  - 分析 `write_skill` / `recall_skills` 是否被有效利用，作为长期策略记忆的证据。
- **错误分析**：
  - 归因到证据缺失（未调用必要工具）、证据误读（调用但解读错误）、整合失败（证据齐备但未正确比较）与格式/解析失败四类；
  - 多选题的"部分正确但集合不等"被单列，说明主指标严格性带来的惩罚。

## 6. 局限与讨论

- **环境依赖**：证据环境依赖离线预计算的 Vista3D 分割与 MedGemma 报告，若真实临床中工具输出分布漂移，策略可能需要重新适配；mock tools 的回放机制也限制了策略探索到缓存之外的观察。
- **基准覆盖**：尽管覆盖 7 家族、6 域、10 层，仍来自单一队列（UK Biobank），人群、影像协议与疾病谱存在偏倚；真实临床的噪声、缺失与非结构化记录未被充分建模。
- **评测口径**：主指标为严格集合匹配，可能低估临床上"方向正确但不完整"的回答；外部 judge 的 insight 分虽与人评做过一致性检验，仍带主观性。
- **安全与部署**：论文将任务定位为证据搜寻与决策支持，而非独立诊断；在真实部署前需要额外的安全性评估与临床验证。

## 7. 结论与整体评价

- **结论**：CASE 把纵向医学推理重构为交互式证据搜寻，用角色化取证智能体、患者级可重放工具环境与 UK Biobank 纵向多模态基准，使"检查什么"这一环节第一次可被系统评估与训练。两阶段流程（RSFT 冷启动 + Agentic RL）配合 OPSD 与链接式 RLAIF，使 8B 紧凑模型在同工具条件下达到甚至超过前沿模型的表现。
- **整体评价**：
  - **贡献层面**：将"证据获取"从隐含假设提升为一等公民任务，基准、工具接口、训练与奖励设计相互咬合，方法论完整度高；
  - **方法层面**：OPSD 以同策略特权视图抑制 RL 中的复述退化，是一种不指定内容、只塑形分布的轻量自蒸馏，思路具迁移性；
  - **实证层面**：分层、配对 bootstrap、错误归因与行为分析齐备，结论可信；
  - **待检验之处**：跨队列泛化、真实临床噪声下的稳健性、以及 judge 奖励与临床价值之间的对齐程度，仍是后续工作的关键。
