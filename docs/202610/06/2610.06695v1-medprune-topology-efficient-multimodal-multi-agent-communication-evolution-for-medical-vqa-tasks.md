## 摘要
尽管医学多模态大语言模型（Med-MLLMs）推动了医学视觉问答（VQA）的发展，但现有受临床工作流程启发的多智能体框架仍受制于交互模式以及冗余通信拓扑所带来的过高计算开销。本文提出MedPrune，一种高效的医学多模态多智能体协作框架，它通过动态剪枝通信拓扑中的节点和边来增强推理能力与token效率。具体而言，我们首先将诊断过程形式化为一个异质通信图，其中节点表示来自不同科室的专科智能体，边刻画科室内与科室间的交互。基于该图，我们引入两种稀疏化机制以实现自适应协作演化：（1）异质节点稀疏化，通过强化学习驱动的拓扑优化，剔除与当前多模态问题无关的专科智能体；（2）异质边稀疏化，通过联合优化任务性能与拓扑复杂度，有选择地仅保留最具诊断显著性的科室内和科室间连接。在全量集和少样本训练设置下开展的大量医学VQA实验证明，MedPrune优于多智能体基线，并在具有强对抗鲁棒性的同时提升了token效率。

## Abstract
While medical multimodal large language models (Med-MLLMs) advance medical visual question answering (VQA), existing clinical workflow-inspired multi-agent frameworks suffer from interaction patterns and excessive computational overhead caused by redundant communication topologies. In this paper, we propose MedPrune, an efficient medical multimodal multi-agent collaboration framework that dynamically prunes both nodes and edges from the communication topology to enhance reasoning ability and token efficiency. Specifically, we first formulate the diagnostic process as a heterogeneous communication graph, where nodes represent specialist agents from various departments and edges capture intra- and inter-departmental interactions. Building on this graph, we introduce two sparsification mechanisms to enable adaptive collaborative evolution: (1) Heterogeneous Node Sparsification, which eliminates task-irrelevant specialist agents irrelevant to the current multimodal question via reinforcement learning-driven topological optimization, and (2) Heterogeneous Edge Sparsification, which selectively retains only the most diagnostically salient intra- and inter-departmental connections by jointly optimizing task performance and topological complexity. Extensive medical VQA experiments under full-set and few-shot training settings prove MedPrune surpasses multi-agent baselines and boosts token efficiency with strong adversarial robustness.

  - **重训练（Training-intensive）**：如 SFT、LoRA/QLoRA、GRPO，模态对齐与事实性更强，但依赖大规模高质量标注数据与昂贵算力。

## 2. 方法论

### 2.1 核心思想
把多轮诊断对话建模为异质图 \(G=(V, E_T, E_S, M)\)：
- **节点 \(V\)**：各科室专科智能体（含主任医师/普通医生）；
- **边**：分为**时序边 \(E_T\)**（跨轮连接）与**空间边 \(E_S\)**（同轮连接），并区分**科室内（intra-）**与**科室间（inter-）**；
- **记忆 \(M\)**：智能体 \(i\) 在轮次 \(t\) 的记忆 \(m_i^{(t)}\) 由 MLLM 函数 \(f_m\) 聚合当前记忆、问题 \(q\) 以及时序/空间邻居消息更新（Eq.1）；T 轮后由总结智能体 \(f_s\) 产出最终答案。

**（3）迭代训练（Algorithm 1）**

## 6. 主要结论与发现

- **性能**：MedPrune 在全量集与少样本设置下均一致超越所有基线，平均性能提升 **3.65%**（Qwen3-VL 8B 上平均 76.56%，HuatuoGPT-Vision 上 76.42%，Qwen3.6-Plus 上 77.86%）。
- **Token 效率**：平均提升 **37.86%**；如 MIMIC-CXR 仅用 6.54k token 达到 42.26，而 CARE 用 11.11k token 仅得 40.08。
- **鲁棒性**：在两类对抗攻击下平均性能仅下降 **3.1%**（保留率约 97.2%），显著优于基线的 71.5%–89.7%。
- **少样本优势**：仅用 10 个样本即可接近全量训练性能，因不更新 MLLM 参数而避免过拟合与表征破坏，降低数据依赖。
- **拓扑演化规律**：随轮次增加，通信自动向少数关键智能体与科室集中，低相关边被逐步抑制。
- **消融结论**：节点稀疏化（NS）与边稀疏化（ES）贡献最大（平均下降 4.17%/4.67%），核范数与渐进剪枝贡献中等，科室选择贡献最小但能加速收敛。
- **迁移性**：跨数据集迁移中仍持续优于 AdaCoMed、MMedAgent-RL、M³Prune、ARG-Designer。
- **提示鲁棒性**：冻结剪枝权重后替换 prompt，最大性能偏差低于 1.1%。

## 7. 优点

- **方法亮点**：
  - **冻结主干、仅学拓扑**：不更新 MLLM 参数，规避重训练的数据与算力瓶颈，且天然兼容不可微的黑盒 API（策略梯度）。
  - **节点+边联合稀疏化**：不仅剪边，还剪掉无关专科智能体，从源头消除首轮 token 开销，比仅调边的自适应方法更彻底。
  - **异质图建模贴合临床**：区分科室内/科室间、空间/时序边，符合真实会诊的多层次结构。
  - **渐进式指数衰减剪枝**：在"过度密集（噪声）"与"过度稀疏（断链）"之间取得平衡，超参实验证明中等剪枝率最优。
  - **鲁棒性来自机制本身**：自适应节点-边剪枝能自动隔离被污染的恶意智能体，无需额外防御模块。
- **实验亮点**：多主干（7B/8B/397B）、多范式基线、统计显著性检验、跨数据集迁移、提示敏感性与超参稳定性验证较完整；训练开销极低（1.5 GPU 小时、18 GB 显存）。

## 8. 不足与局限

- **超参未穷举优化**：节点丢弃率 α、噪声容忍 δ 等关键超参未在所有科室组成与影像模态上系统寻优；最优剪枝强度可能随问题复杂度与协作专家数变化，需要更自适应的剪枝调度。
- **科室选择依赖外部启发式**：当前用冻结 MLLM 做相关性打分排序，未直接纳入强化学习优化，存在额外外部排序依赖，流程不够端到端。
- **可扩展性未验证**：仅验证了最多 3 个科室、15 个智能体的场景；面对数十个亚专科智能体时，组合动作空间会急剧膨胀，策略梯度优化的可解性与效率收益尚未压力测试。
- **实验覆盖的偏差风险**：
  - 对抗攻击与部分分析仅在 MIMIC-CXR 上完成，鲁棒性结论的泛化性待确认；
  - 跨数据集迁移仅两个场景，且其中一例使用 PMC-OA 训练；
  - 少样本设置最小仅 10 例，统计波动可能较大；
  - 闭源 397B 模型无法微调，导致该主干上的对比不完整。
- **应用限制**：智能体角色与提示模板为人工设计（11 个候选科室、主任/医生分工），存在人工先验依赖；未开展真实临床部署验证，也未评估对罕见病、多病共存等极端病例的表现；诊断安全性（误诊风险）缺乏临床层面的评估。
