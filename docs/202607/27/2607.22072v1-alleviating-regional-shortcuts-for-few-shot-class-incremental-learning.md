## 摘要
少样本类增量学习（FSCIL）旨在仅用少量样本增量学习新类别，同时避免遗忘基类。然而，当前方法倾向于将新类样本误分类为基类，我们发现这是由于模型在新类样本上过度关注基类判别性区域所致。本文旨在探索其潜在机制以提供解释与解决方案。首先，我们通过组合视角分析新类样本上被迁移和重用的空间模式。然后，通过大量实验和理论分析，我们从经验和理论上证实，模型在基类训练中存在一种捷径，自然导致对最具判别性区域（原始特征）的过度关注，我们将其称为区域捷径。最后，基于这一解释，为解决该问题，我们提出一种基于组合学习的方法，学习两个原始特征集（公共集与判别集），通过约束模型学习并利用公共原始特征集进行基类和新类识别，从而缓解区域捷径。在标准FSCIL基准上的大量实验表明，我们的方法在准确性和可解释性上均比现有最先进方法有一致提升。

## Abstract
Few-shot class-incremental learning (FSCIL) aims to incrementally learn novel classes with only a few samples while avoiding forgetting base classes. However, current methods show a tendency to misclassify novel-class samples into base classes, which we find to be caused by the excessive focus on base-class-discriminative regions on novel-class samples. In this work, we aim to explore the underlying mechanism for an interpretation and solution. We first provide a compositional view to analyze the transferred and reused spatial patterns on novel-class samples. Then, through extensive experiments and theoretical analysis, we identify both empirically and theoretically that a shortcut exists in the model's base-class training, which naturally forms the excessive focus on only the most discriminative regions (primitives), which we term as the regional shortcut. Finally, based on this interpretation, to address this problem, we propose a compositional-learning-based method to learn two primitive sets (a common set and a discriminative set), which alleviates the regional shortcut by constraining the model to learn and utilize the common primitive set for base- and novel-class recognition. Extensive experiments on standard FSCIL benchmarks demonstrate the effectiveness of our approach, yielding consistent improvements over existing state-of-the-art methods in both accuracy and interpretability.

- **问题**：少样本类增量学习（FSCIL）中，模型在增量阶段容易将新类样本误分类为基类，导致新类性能受限。
- **发现**：通过可视化热图，发现模型在新类样本上过度关注与基类相关的小部分判别性区域（例如，将玉米误判为蚂蚁是因为只关注了玉米上的蚂蚁状昆虫），而忽略了新类自身的关键特征。
- **根源**：作者提出“**区域捷径**”（Regional Shortcut）概念——基类训练时，模型倾向于只聚焦于最具判别性的原始特征（primitives），导致学习到的原始集合缺乏语义多样性和空间覆盖，这种偏差在新类上持续存在，阻碍了模型注意力向新类判别性区域的转移。
- **研究目标**：解释这一现象的内在机制，并提出缓解方法，提升FSCIL在新类上的准确性和模型可解释性。

## 2. 方法论

### 核心思想
基于组合学习（Compositional Learning）视角，将图像视为由多个视觉原始特征（primitives）组合而成。理想情况下，基类训练应学习多样化的原始集，使新类能通过重新组合这些原始特征进行识别。但区域捷径导致模型只学到少量判别性原始特征。为此，作者提出显式构建两个原始集：
- **公共原始集（Common Primitive Set）**：捕获跨类共享的语义模式，鼓励模型学习可迁移的、语义丰富的表示。
- **判别原始集（Discriminative Primitive Set）**：保留类间判别性特征，维持基类性能并缓解灾难性遗忘。

### 关键技术细节（两阶段框架：ARS-CDP）

#### 阶段一：原始集构建（Primitive Set Building Stage）
- **特征提取器**：使用基类数据训练得到特征提取器 \(\phi(\cdot)\)（含编码器 \(h(\cdot)\) 和池化层 \(g(\cdot)\)），输出特征图 \(F \in \mathbb{R}^{d \times h \times w}\)，每个空间位置视为一个原始特征。
- **公共原始集构建**：
  - 通过MLP生成空间掩码 \(M_u\)，得到公共特征图 \(F_u = M_u \odot F\)。
  - 利用注意力机制将 \(F_u\) 重构为 \(\bar{F}_u\)，并基于**相似性引导损失** \(L_{\text{sim}}\)（Jensen-Shannon散度）迫使公共特征图捕捉基类间的共享语义，同时抑制地面真值类的影响。
- **判别原始集构建**：
  - 通过注意力机制重构判别特征图 \(F_i\)。
  - 使用**原型中心损失** \(L_{\text{pro}}\) 迫使判别特征图聚焦于类特定特征。
- **原始重建损失** \(L_r\)：结合公共和判别特征图重建原始特征图，平衡两类信息的贡献。

#### 阶段二：原始集利用阶段（Primitive Set Utilization Stage）
- 冻结已学到的公共和判别原始集，微调特征提取器 \(\phi_{\text{pr}}(\cdot)\) 和新分类器 \(W_{\text{pr}}^{\text{base}}\)。
- 对基类样本进行混合样本变换（CutMix风格），增强原始组合的多样性。
- 分别对原始特征图、公共特征图和判别特征图进行全局平均池化，拼接为 \(3d\) 维的原始增强表示 \(\phi_{\text{pr}}(x)\)。
- 使用余弦分类器和交叉熵损失，同时继续使用 \(L_{\text{sim}}\) 和 \(L_{\text{pro}}\) 约束。
- 增量阶段：基类分类器固定为类平均嵌入，新类分类器通过平均嵌入计算，无需重新构建原始集。

### 公式（文字说明）
- 整体损失：\(L = L_{\text{ce}} + \lambda L_{\text{sim}} + \beta L_{\text{pro}}\)
- 相似性引导损失：使用Jensen-Shannon散度对齐公共特征图的预测分布与图像-基类相似度分布（抑制地面真值类）。
- 原型中心损失：余弦距离最小化判别特征图池化向量与地面真类权重之间的距离。
- 原始重建损失：交叉熵损失，使重建特征图 \(F_r\) 与原始特征图 \(F\) 在空间位置上匹配。
