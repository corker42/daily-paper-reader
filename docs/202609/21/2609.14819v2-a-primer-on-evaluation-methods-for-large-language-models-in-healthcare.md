## 摘要
大型语言模型（LLM）在医学中的应用范围日益扩大，其评估对于确保它们带来益处而非伤害至关重要。这种评估可能比传统机器学习更具挑战性，原因有很多，包括概率性和开放式的输出，以及会随提示设计和累积上下文而变化的行为。本综述涵盖LLM评估的四个关键领域：研究设计原则、统计方法、能力评估和临床情境评估。能力评估考虑不同的基准，包括多项选择、智能体和多轮基准，以及token使用量等操作指标。临床情境评估涉及确定自由文本输出的准确性，例如人工审核和LLM作为评判者（LLM-as-a-judge），以及临床试验方法。在各部分中，我们描述了基本概念和潜在陷阱，同时强调使评估方法与研究问题保持一致的重要性。总体而言，本文旨在为设计和执行对医疗健康领域LLM的严谨评估提供务实基础。

## Abstract
Large language models (LLMs) have a growing range of applications in medicine, and their evaluation is critical for ensuring they provide benefit and not harm. This evaluation can be more challenging than traditional machine learning for many reasons, including probabilistic and open-ended outputs, and behavior that shifts with prompt design and accumulated context. This review covers four key areas of LLM evaluation: principles of study design, statistical methods, capability evaluation and clinical context evaluation. Capability evaluation considers different benchmarks, including multiple-choice, agentic and multi-turn benchmarks, alongside operational metrics like token usage. Clinical context evaluation addresses establishing accuracy of free text outputs, such as human review and LLM-as-a-judge, and clinical trial approaches. Across sections, we describe underlying concepts and potential pitfalls, while emphasizing the importance of aligning evaluation methods with the research question. Together, this article aims to provide a pragmatic basis for designing and executing rigorous evaluations of healthcare LLMs.

### 2.1 研究设计原则

- **设计框架**：需明确目标、端点、零假设与备择假设，并尽可能在**研究方案或统计分析计划（SAP）**中预先设定；评估可以是"达到最低性能阈值"或"模型间比较"，也可为描述性的操作指标（算力、成本）。
- **参考标准**：由研究问题决定。任务型评估常用离散答案（如诊断有/无）；严谨程度不一，可来自病历中已有的 ICD-10 编码，也可来自专家小组共识。自由文本生成往往**不存在唯一正确答案**，需依赖结构化人工或 LLM 评估。
- **训练/测试数据**：LLM 训练语料庞大且不公开，分层应用（prompt 生成、智能体架构）还需额外开发。测试集的两大关切：
  - **数据污染**：测试数据可能已进入训练语料（如已发表病例报告不宜用于诊断性能测试）；基准虽意在规避污染，但自身也可能被纳入训练语料。
  - **泛化性**：需跨机构验证；测试集的人口学代表性需显式考虑，通常应预设**年龄组、性别、种族、族裔、站点**的亚组分析，以发现聚合指标掩盖的性能差异；应纳入真实世界的轻症与不确定表现，可用**连续病例选择**实现。
- **数据要素的时间性**：评估量表只能提供临床路径相应时点可得的数据，不得混入下游诊断或治疗步骤。
- **模型随时间稳定性**：可**锁定模型版本**而非使用持续更新模型；使用**无状态单轮 API 调用**避免先前病例影响后续输出；重复测试以检查响应演化。
- **运行间变异**：对每例重复运行、模型比较时对同一批病例做配对分析；报告采样设置与跨运行方差；利用 temperature、固定随机种子等 API 高级设置降低随机性。
- **方法学 LLM（methodologic LLM）**：LLM 也可作为评估执行者，如按纳入标准筛选病例。可用多个方法学 LLM 执行同一任务并对部分输出做人工复核；提示词须无歧义且在论文中报告。
- **报告清单**：TRIPOD-LLM（模块化，适配不同 LLM 研究设计与任务）、放射领域 FLAIR 等，可作为设计阶段检查表。
- **样本量与效能**：取决于研究问题与预期变异，同时受病例可得性、时间、经费约束；比较研究应事先指定**具有临床意义的差异**，并据此做样本量计算（基于效能或可接受宽度的置信区间）。
- **置信、显著性与意义**：p<0.05 并不证明差异真实、有临床意义或足够大；大样本下极小差异也可显著，因此应报告**置信区间**。还可采用贝叶斯等替代范式，以及**分层证据框架**（回顾性基准 → 静默前瞻部署 → 与常规诊疗的随机对照）。

### 2.2 统计方法

**分类输出（离散）**

- 二分类：敏感度、特异度、阳性/阴性预测值、准确率；类别不平衡时准确率具误导性（如患病率 5% 时"全答否"可得 95% 准确率），应使用**平衡准确率**与 **F1**。
- 多分类/序数：Cohen's κ（校正机遇一致）、**加权 κ**（序数）；**宏平均**（各类等权）与**微平均**（各例等权）在类别不平衡时分歧，须报告所选方式。
- 多标签：**Dice 系数**、**Jaccard 指数**（交并比）度量集合重叠；**Tversky 指数**可对不同错误（漏诊 vs. 误加）赋不同权重。
- 判别力：以不同阈值绘制**ROC 曲线**，**AUC** 表示随机正例得分高于随机负例的概率（0.5 为机遇，1 为完美）；负类不平衡且需关注假阳性影响时用 **AUPRC**。
- 校准：当概率直接展示给临床医生或馈入下游决策规则时重要。**Brier 分数**为单一汇总值（混合了校准与判别）；**决策曲线分析（DCA）**计算在阈值概率范围内的净获益，并与"全治/不治"比较，适用于输出直接驱动临床行动的情形。

**数值输出**

- **相关**（Pearson 线性、Spearman 单调）、**一致**（ICC、CCC）、**误差**（RMSE 对较大偏差惩罚更重、MAE）回答三个不同问题，必须分开报告；相关不蕴含一致性。

### 2.3 能力评估（Capability Evaluation）

- **基准定义**：固定任务数据集 + 预定义正确答案 + 固定评分流程；便于模型横向比较，但也可被训练语料污染。
- **多项选择/知识基准**：MedQA（USMLE 风格）。作为早期信号有用，但日益被认为**不足以检验临床就绪度**（偏事实回忆、单时点，而非多步迭代工作流）。
- **多任务与智能体基准**：
  - MedHELM：基于临床医生验证的 **121 项真实临床任务**分类体系（决策支持、病历生成、患者沟通、研究、行政），价值在于广度；局限为聚合分数掩盖任务级差异、任务未必覆盖完整临床流程、公开基准存在污染风险。
  - 智能体基准：MIRA、MedAgentBench、Physician Bench、HealthAgentBench，评估规划与工具使用、在复杂环境中导航的能力。
- **多轮基准**：常用 LLM-as-a-judge 对固定对话集按多准则（事实准确性、沟通质量）打分；也有用**患者演员**或 LLM 智能体基于预设病例生成对话以模拟真实对话的随机性，但此类模拟用户本身需进一步验证。
- **推理基准**：评估过程而非仅终点（区分"推理得解"与"关键词锚定猜答"）。
  - Chain-of-Thought（CoT）提示；MedThink-Bench、MedR-Bench、Open-XDDx、ER-Reason（参考推理有专家撰写或机器生成之别）；**脚本一致性测试**考察新增数据如何调整输出。
  - **忠实性警示**：研究表明模型陈述的推理与实际驱动输出的过程可能背离——截断/插入错误常不改变最终答案（中间步骤非"承重"）；模型会为错误答案编造 CoT 且不提及偏置特征。
  - 参数化方法：擦除权重中特定推理步的信息后检验预测是否改变；**J-space / Jacobian lens**（Anthropic）揭示未言明的中间表征；探针分类、激活修补。
- **操作指标**：token 用量（输入+输出）、每次查询成本、延迟（决定能否嵌入实时临床流程）、停机/错误率与负载行为、能耗与可持续性；可调参数 **temperature**（医疗通常取低值）与 **Top-P**（二者通常只调其一），以及最大输出 token 数。

### 2.4 临床情境评估（Clinical Context Evaluation）

- **NLP 指标**：
  - 重叠类：BLEU、ROUGE、METEOR，基于 n-gram 共享计数，要求精确匹配，会惩罚正确但换一种说法的答案。
  - 嵌入类：BERTScore、余弦相似度，能奖励改写，但对否定、数字、命名实体等临床关键细节不敏感。
  - 两类方法原为较短、受限文本设计，**对 LLM 长开放输出普遍被认为不充分**。
  - 可读性：Flesch-Kincaid 年级水平、Flesch Reading Ease，只测形式不测正确性，须与准确性指标并列报告，对患者面向文本尤为重要。
- **人工审核**：由领域专家依结构化评分量表评估，可显式纳入临床安全性、数据隐私、伦理对齐等医疗特有维度。**QUEST** 提供文献衍生维度，替代各自为政的量表并支持**评分者间一致性**与校准。示例：医生审阅 AI 生成出院小结时使用覆盖错误类型、伤害严重度与可能性的结构化工具（AHRQ Common Format Harm Scale）。人工审核是金标准但**受规模化限制**；众包评估被提出作为可能的补充。领域专用框架如面向消费级健康/保健的 **SHARP**（安全、有用、准确、相关、个性化），体现评估标准不可跨情境移植。
- **LLM-as-a-judge**：按预设准则与评分框架打分，易扩展，适合评量临床量表遵从度或相关性等定性特征。关键实践：给明确指令与参考/范例；**评判 LLM 在研究期间固定**；最好与受评模型**不同家族**（同家族模型倾向偏好自身输出）；必须抽样做人工复核。**忠实性指标**：groundedness（陈述可回溯到支持段落）与幻觉率；工具如 **ACUEval**（将摘要拆为原子内容单元再与原文比对）、**VeriFact**（核查出院小结"住院经过"等生成文档中的逐条陈述）。
- **临床试验方法**：超越输出评估，用传统临床试验方法学评估 LLM 对临床结局的影响，如在**提供者或机构层面随机化**，比较使用与不使用 LLM 的组别。挑战在于平衡"归因清晰"的端点与"临床意义更大"的端点（如死亡率，混杂因素多，需恰当控制）。

  - 对商业模型与开源模型的**覆盖不对称**：文中提及的若干基准与工具依赖可访问的 API 或特定平台，对资源受限团队的可行性讨论不足。
  - 由于是"入门指南"定位，论文对争议性议题（如 LLM-as-a-judge 的效度、合成患者模拟的生态效度、贝叶斯范式在监管中的可接受度）采取**并列陈述而非裁决**，这对初学者友好，但可能让读者难以形成明确取舍。
- **内部一致性**：四支柱框架与四张表格之间对应关系清晰，术语（如"reference standard""run-to-run variation"）在全文中使用一致，未见明显自相矛盾；但"评估"一词在"模型性能评估"与"临床影响评估"两个层面间切换时，偶有需要读者自行消歧之处。

## 6. 主要结论与贡献

- **核心结论**：不存在放之四海而皆准的医疗 LLM 评估指标；评估的严谨性取决于**研究问题、参考标准、目标临床决策与预设统计分析计划**四者的对齐。任何脱离临床用途谈"高分/低分"的做法都缺乏意义。
- **方法学贡献**：
  1. 提出并组织了一个**四支柱（研究设计、统计方法、能力评估、临床情境评估）**的评估框架，并以流程图串联为可操作的工作流；
  2. 系统辨析了易被混淆的统计概念（相关/一致/误差、准确率/平衡准确率/F1、ROC-AUC/AUPRC、宏平均/微平均），并给出**适用条件**而非仅罗列定义；
  3. 将**推理忠实性**（而非仅推理正确性）提升为评估的一等公民，介绍了 CoT 忠实性检验、脚本一致性测试、Jacobian lens 等前沿手段；
  4. 强调了医疗特有维度（安全性、隐私、伦理、患者可读性）与**领域专用框架**（QUEST、SHARP、AHRQ Harm Scale）的必要性；
  5. 指出**分层证据框架**（回顾性基准 → 静默前瞻部署 → 随机对照）是通向临床采纳的路径，而非单次基准得分。
- **实践性贡献**：为研究者、临床医生、期刊审稿人与监管者提供了一份可核对的清单式参考，并与 TRIPOD-LLM、FLAIR、MI-CLEAR-LLM 等报告规范形成互补。

## 7. 局限性

- **性质限制**：作为叙述性入门指南，本文不提供新数据、不做元分析，其结论为**规范性建议**而非实证发现，无法量化"按此框架评估会提升多少模型可靠性"。
- **时效性**：LLM 与基准迭代极快（参考文献多集中于 2023–2026），文中列举的具体基准与工具可能迅速过时；框架层面（研究设计、统计对齐）相对稳定，工具层面需读者自行更新。
- **覆盖偏差**：以英文文献与欧美机构视角为主，对非英语临床场景、低资源医疗系统、监管体系差异（如 FDA、EMA、NMPA 路径）讨论有限。
- **实施门槛**：文中推荐的许多做法（专家小组参考标准、患者演员、多模型方法学 LLM、重复运行配对分析、人工抽样复核）成本高昂，论文虽承认受"病例可得性、时间、经费"约束，但未给出**分级的最低可行方案**（如小型团队可负担的最小严谨性清单）。
- **未触及的议题**：对模型更新导致的**版本漂移**、持续学习系统的再评估频率、多模态（影像+文本）评估、以及评估结果的**公开发布与可复现性基础设施**着墨相对较少。

## 8. 对后续研究与实践的启示

- **研究层面**：
  - 应在**SAP 中预先设定**主端点、参考标准、亚组与样本量，并将"具有临床意义的差异"显式量化；
  - 报告须完整披露**提示词、采样参数、模型版本、运行次数与方差**，以便复现；
  - 优先开展**跨机构、跨人群的外部验证**，并对年龄、性别、种族、族裔、站点做预设亚组分析；
  - 从"单点基准得分"转向**推理过程、忠实性、操作成本与临床结局**的多维评估；
  - 在条件允许时，推进**静默前瞻部署与随机对照**，以弥合基准表现与真实世界获益之间的鸿沟。
- **实践/治理层面**：
  - 医疗机构与监管方可将四支柱框架用作**采购、上线与审计**的检查表；
  - 期刊与会议可要求投稿遵循 TRIPOD-LLM 等清单，并公开评估工具与评分量表；
  - 对患者面向的生成文本，应**强制并列报告可读性与准确性**指标，并纳入临床安全性审查。
- **方法学层面**：
  - LLM-as-a-judge 需固定评判模型、跨家族使用、并抽样人工复核，其自身的效度仍待系统研究；
  - 合成患者/模拟用户、机器生成参考推理等低成本替代方案，其**生态效度**需独立验证后方可替代金标准。
