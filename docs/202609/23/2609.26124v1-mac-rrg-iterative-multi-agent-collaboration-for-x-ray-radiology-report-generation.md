## 摘要
尽管基于大语言模型（LLM）和知识图谱增强的放射学报告生成（RRG）方法取得了显著进展，现有技术仍存在固有缺陷。传统仅依赖LLM的模型缺乏结构化医学先验知识，导致频繁出现医学幻觉且诊断可解释性较低。当前知识图谱增强方案采用单源知识的静态单轮知识融合，无法根据生成反馈动态更新知识。本文提出一种新颖的用于X射线放射学报告生成的迭代式多智能体协作框架，称为MAC-RRG。受多智能体技术启发，我们的框架基于任务解耦与协作推理构建了一种闭环优化范式。具体而言，该框架首先通过视觉编码器和基础LLM从输入X射线图像生成初步放射学报告。随后，多模态知识图谱（MM-KG）智能体从医学知识图谱中挖掘结构化的疾病关联与解剖学知识，而辅助知识智能体从公共医学数据库中提取非结构化领域知识。双智能体获取的多源知识被融合并嵌入，以指导LLM迭代优化初始报告。在包括IU X-ray、MIMIC和CheXpert Plus在内的主流X射线RRG数据集上进行的大量定量与定性实验，充分验证了我们所提方法的优越性。源代码和预训练模型已在 https://github.com/Event-AHU/Medical_Image_Analysis 发布。

## Abstract
Despite the remarkable progress of LLM-based and knowledge graph-augmented Radiology Report Generation (RRG) methods, existing techniques still suffer from inherent defects. Conventional LLM-only models lack structured medical prior knowledge, resulting in frequent medical hallucinations and low diagnostic interpretability. Current knowledge graph-enhanced schemes adopt static one-round knowledge fusion with single-source knowledge, incapable of dynamic knowledge updating according to generation feedback. This paper proposes a novel Multi-Agent Collaborative iterative framework for X-ray Radiology Report Generation, termed MAC-RRG. Inspired by multi-agent technology, our framework constructs a closed-loop optimization paradigm based on task decoupling and collaborative reasoning. Specifically, the framework first generates a preliminary radiology report from input X-ray images via a vision encoder and a basic LLM. Subsequently, a multimodal knowledge graph (MM-KG) agent mines structured disease correlation and anatomical knowledge from medical knowledge graphs, while an auxiliary knowledge agent extracts unstructured domain knowledge from public medical databases. The multi-source knowledge acquired by dual agents is fused and embedded to guide the LLM in iteratively refining the initial report. Extensive quantitative and qualitative experiments on mainstream X-ray RRG datasets, including IU X-ray, MIMIC, and CheXpert Plus, fully verify the superiority of our proposed method. The source code and pre-trained models have been released on https://github.com/Event-AHU/Medical_Image_Analysis

## 1. 核心问题与整体含义（研究动机与背景）

- **任务背景**：X 射线胸片是临床筛查、急诊诊断与呼吸系统疾病监测中最常用的影像模态之一。放射学报告生成（RRG）旨在自动生成与影像对应的专业诊断描述，可减轻放射科医生工作负担、缩短患者等待时间，并缓解专业放射科医师短缺地区的诊疗可及性问题。
- **现有方法的两类固有缺陷**：
  - **纯 LLM 基线范式**：仅融合原始 X 射线图像提取的视觉特征，未引入结构化医学先验（如疾病关联、解剖学先验），面对复杂影像征象时易产生医学幻觉，且诊断推理缺乏可解释性。
  - **知识图谱增强范式**：虽在一定程度上缓解外部知识不足，但知识图谱特征在前向推理中以"一次性静态"方式融合，无法根据初步生成报告动态调整与迭代检索所需知识；且仅依赖知识图谱中的结构化图知识，缺乏医学文献、临床指南等非结构化文本知识的补充。
- **共同缺陷**：上述两类方法均采用一次性生成流水线，缺少反馈闭环，初始报告中的实体遗漏与描述偏差无法被外部医学知识持续验证与修正。
- **研究动机**：受多智能体技术启发，利用其任务解耦、专业化分工、动态交互推理与迭代闭环优化的优势，构建针对 X 射线 RRG 的迭代式多智能体协作框架 MAC-RRG，以弥补可解释性不足、静态知识融合与非迭代生成三大瓶颈。

## 2. 方法论

### 2.1 核心思想
- 以**初步报告作为"实体感知桥梁"**，连接视觉证据与外部医学知识；通过两个角色专业化的知识智能体分别挖掘结构化与非结构化知识，经融合后指导 LLM 迭代精炼报告，形成闭环优化范式。

### 2.2 关键技术细节与流程

- **阶段一：初始报告生成与实体抽取**
  - 视觉编码器采用 Swin Transformer 将每张视图编码为视觉 token 序列 `V = fv(I) ∈ R^{Nv×dv}`，投影至 LLM 隐藏维度后自回归生成初稿报告 `R0`。
  - 实体抽取模块对 `R0` 分句、规范化标点与大小写，基于放射学实体词典做词法匹配，仅保留 **anatomy（解剖）** 与 **disorder（疾病）** 两类实体，跨句去重后形成检查级实体集合 `E = {(ei, ti)}`。
  - 使用初稿进行实体选择的两点好处：将外部知识查询限定为图像条件下的临床概念；为图分支与检索分支提供共享实体集，保证结构化与非结构化知识在 token 层可比。

- **阶段二：MM-KG 智能体（结构化知识）**
  - 医学知识图谱存储为带权三元组集合。对每个实体 `ei` 搜索源/目标匹配的三元组，按频次排序保留 top-`Kg`（默认 10）邻居，形成 `Gi = {(ei, rij, nij)}`。
  - 中心实体、邻居实体与关系标签均由**冻结的 Bio_ClinicalBERT** 编码：`Ĝi = {(φ(ei), φ(nij), φ(rij))}`，保留解剖区域—影像征象—疾病之间的局部关系结构。

- **阶段三：知识智能体（非结构化知识）**
  - 基于 PubMedVision 构建检索语料：抽取胸部 X 射线相关视觉问答样本，由 LLM 总结为结构化知识条目，形成知识片段库。
  - 对每个实体构造查询 `qi = [R0; ei; ti]`，先用 **BGE-M3** 编码检索 top-N（N=10）候选块，再由 **BGE reranker** 重排保留 top-Kr（当前每实体 1 条），跨实体合并去重得证据列表 `C = {c1,…,cNr}`。
  - 每个块经冻结 Bio_ClinicalBERT 编码并做带注意力掩码的均值池化 + 归一化，堆叠成 `R ∈ R^{Nr×768}`。相较直接拼接长文本提示，该设计更紧凑且保留实体相关证据。

- **知识融合模块**
  - **图分支**：采用关系感知图注意力编码器，将中心实体嵌入变换为 Query，邻居 Key 为邻居嵌入与边嵌入之和，按注意力权重聚合邻居 Value，再经 MLP 得到图上下文表示 `gi`，拼接为图知识 token `G`。
  - **检索分支**：如上得到 `R`。
  - **跨源融合**：将两分支投影至与视觉特征同维空间（`˜G = WgG`，`˜R = WrR`），与图像 token 直接拼接：`Z = [V; ˜R; ˜G]`，再经 `E = LayerNorm(Wllm Z)` 投影至 LLM 隐藏空间，与文本生成提示共同构成前缀。

- **损失函数**
  - 以自回归语言建模为目标，条件前缀 `H = Concat(E, P)`，对目标报告 `Y` 建模 `pθ(Y|H) = ∏ pθ(yt|y<t, H)`。
  - 损失为平均负对数似然 `LLM = -(1/T) Σ log pθ(yt|y<t, H)`；训练时对文本提示、视觉 token、图知识 token、检索知识 token 对应标签置 −100，仅真实报告 token 参与损失。

## 6. 主要结论与发现

- **IU-Xray**：BLEU-1~4 为 0.488/0.330/0.249/0.197，ROUGE-L 0.400，METEOR 0.223，CIDEr 0.703；在 BLEU-3、BLEU-4、ROUGE-L、CIDEr 上取得最优，说明在连续医学短语、复杂语义片段与整体报告内容上优势明显。
- **CheXpert Plus**：BLEU-1~4 为 0.375/0.232/0.154/0.105，ROUGE-L 0.267，METEOR 0.151，CIDEr 0.121；在 BLEU-2~4、ROUGE-L、METEOR 上最优，BLEU-1 略低于 Token-Mixer、CIDEr 略低于 R2GenGPT 但差距很小。
- **MIMIC-CXR**：BLEU-1~4 为 0.409/0.258/0.177/0.128，ROUGE-L 0.285，METEOR 0.165，CIDEr 0.248；在高阶 BLEU 上最优，整体具竞争力。
- **临床效能（CheXpert Plus）**：F1 0.295、Precision 0.350、Recall 0.274；F1 与 Precision 均为最优，F1 较 R2GenGPT（0.260）显著提升，Precision 超过此前最高的 VLCI；在识别异常与避免误报之间取得更好平衡。
- **消融结论**：
  - MM-KG 智能体与知识智能体均能独立提升基线，两者与知识融合模块联合使用时整体最优。
  - top-K=10 在 BLEU-4 与 METEOR 上最佳；邻居过多会引入冗余或弱相关信息。
  - 实体类型采用 **Anatomy + Disorder** 时 BLEU-4 与 METEOR 最优；加入 Device 或全部实体类型反而下降，说明过多实体类型引入噪声。
  - 检索语料以约 400 块（去重后 393 条）为最佳平衡点；增至 1500 块时所有 NLG 指标下降。
  - 融合策略中**直接拼接**优于 self-attention 与 cross-attention，后者可能放大检索噪声或弱相关邻居的影响。
  - 最终模型选择 ckpt2，兼顾 BLEU-4（0.105）与最高 Precision（0.350）及较优 F1/Recall。

## 7. 优点

- **方法设计亮点**：
  - 首次将**角色专业化多智能体协作 + 迭代闭环**引入 X 射线 RRG，突破静态单轮知识融合与一次性生成的限制。
  - 结构化（MM-KG）与非结构化（知识智能体）双源知识互补，且两分支共享同一实体集，保证 token 级可比性。
  - 以初稿报告作为查询锚点，将检索限定为图像条件下的临床实体，避免全局相似度检索带来的噪声证据。
  - 知识融合模块采用关系感知图注意力编码 + 紧凑连续表示拼接，避免冗长文本提示，兼顾效率与知识保留。
- **实验设计亮点**：
  - 在 3 个不同规模与复杂度的公开数据集上验证，泛化性证据较充分。
  - 同时报告 NLG 与临床 CE 指标，强调临床准确性而非仅语言流畅度。
  - 消融维度覆盖组件、超参数、实体类型、融合策略，并对检查点选择给出明确的临床权衡依据。
  - 提供结构化/文本知识证据与生成报告的双重可视化，增强可解释性与说服力。

## 8. 不足与局限

- **对初稿质量的依赖**：实体抽取完全来自初始报告，若初稿遗漏或错误描述异常，两个智能体将检索到不完整或弱相关的外部证据，导致误差累积；缺乏鲁棒的实体抽取与草稿纠错机制。
- **融合策略的简化**：最终采用直接拼接而非注意力融合，虽在实验中更稳定，但可能未充分挖掘图知识与检索知识之间的深层交互。
