## 摘要
强化学习（RL）为医疗决策提供了一种自然的语言，因为这类决策的后果会随时间逐步显现；然而，大多数已报告的进展仍远未成为常规干预。现有综述多按算法或临床应用来组织该领域。我们则通过一条证据阶梯来审视医疗强化学习：问题构建、回顾性识别、策略估计、压力测试、前瞻性评估和生命周期监测。这一视角将临床治疗、患者参与和卫生系统运营联系起来，同时揭示出一个反复出现的缺口：策略在历史数据集中得分高，并不等于有证据表明它能改善照护。我们综合了每一级阶梯上的假设与失效模式，明确了哪些证据可以跨场景迁移、哪些不能，并提出了面向累积性评估的报告实践。Restless bandits 仅作为一个特例纳入，而不是组织框架。核心教训是：医疗强化学习应被评估为嵌入不断变化的社会技术系统中的一种干预，而不只是回顾性奖励的优化器。

## Abstract
Reinforcement learning (RL) offers a natural language for healthcare decisions whose conse- quences unfold over time, yet most reported progress remains far from routine intervention. Ex- isting surveys organize the field by algorithm or clinical application. We instead review healthcare RL through an evidence ladder: problem formulation, retrospective identification, policy estima- tion, stress testing, prospective evaluation, and lifecycle monitoring. This view connects clinical treatment, patient engagement, and health-system operations while exposing a recurring gap: evi- dence that a policy scores well in a historical dataset is not evidence that it will improve care. We synthesize the assumptions and failure modes at each rung, identify what evidence can and can- not transfer across settings, and propose reporting practices for cumulative evaluation. Restless bandits are included as one special case, not as the organizing framework. The central lesson is that healthcare RL should be evaluated as an intervention embedded in a changing sociotechnical system, rather than only as an optimizer of a retrospective reward.

## 2. 方法论

### 2.1 核心思想：证据阶梯（Evidence Ladder）

论文以"阶梯"取代算法/疾病分类，共六级，**高层级依赖但不替代低层级**（对应文中 Table 1）：

| 层级 | 核心问题 | 典型证据 |
|---|---|---|
| 1. 形式化（Formulation） | 决策问题在临床上是否忠实？ | 利益相关方评审；状态/动作/奖励的合理性论证 |
| 2. 识别（Identification） | 历史数据能否支撑该比较？ | 覆盖度、混杂、缺失、时间维度审计 |
| 3. 估计（Estimation） | 候选策略是否改善期望结局？ | 多种 off-policy 估计器、不确定性、基线 |
| 4. 压力测试（Stress testing） | 性能能否在合理变化下存活？ | 亚组、敏感性、分布漂移、最坏情形测试 |
| 5. 前瞻评估（Prospective study） | 干预在真实工作流中是否有效？ | 静默试验、微随机化试验、受控放量 |
| 6. 生命周期（Lifecycle） | 部署后价值能否持续？ | 监测、漂移响应、再审计、治理 |

### 2.2 方法学基础（四大支柱）

- **离线策略学习**：医疗 RL 通常只能在固定日志上学习，核心难点是行为策略与学习策略间的分布偏移。应对手段包括行为正则化、悲观/保守价值估计（CQL、IQL）、基于模型的规划、不确定性感知方法。作者强调：**这些都不能替代追问"历史动作为何被选中""哪些关键变量缺失"**；表示学习压缩出的预测状态未必保留治疗效应修饰因子；缺失本身可能编码临床注意力，插补可能抹掉该信号。
- **因果推理与 off-policy evaluation（OPE）**：潜在结果/结构因果框架澄清一致性、正性（positivity）与序贯可交换性；边际结构模型、g-computation、双稳健估计处理时变混杂。OPE 是候选策略与日志数据之间的桥梁——重要性采样无偏但方差大、直接建模稳定但易误设、双稳健折中。**估计器之间的一致性只是诊断，不是忽略其共同假设的许可**。
- **安全、约束与人类权威**：安全 RL 区分"价值不确定性"与"不可接受行为的约束"；约束 MDP 优化期望成本，但对罕见严重违规可能不足，需动作级护栏与临床医生权威。人类参与会改变被评估的策略本身（接受/修改/延迟/忽略 → 联合人-AI 策略），自动化偏见与警报疲劳可造成伤害。
- **公平与分布式价值**：不公平可经可及性、测量、标签、历史治疗与部署进入；序贯系统额外引入反馈回路（少分配 → 观测收益低 → 合理化未来的少分配）。**不存在通用公平度量**；应报告多重分布性结果并显式说明规范性选择，亚组估计也需带不确定性。

### 2.3 提出的报告规范："证据卡"（Evidence Card）

作者提出与阶梯对齐的结构化记录（非监管认证、非新标量评分），包含七部分：

1. **决策情境**：决策者、受影响人群、节奏、时域、可用动作、建议性还是自主性；区分"记录的医嘱"与"实际给予的治疗"；分配类系统需说明共享预算与个体间耦合方式。
2. **目标与约束**：列出全部奖励分量、尺度与时间、硬/软约束及参与选择的利益相关方；至少一项针对关键权重/时域的敏感性分析；替代结局需说明其与患者获益的关联证据；无法无争议合并时应报告帕累托前沿或分布性结果。
3. **数据来源与识别**：站点、日历期、纳入标准、缺失、删失、动作频率、临床实践变化；序贯正性应对临床重要状态逐一评估（百万级记录也可能对"罕见状态下的罕见动作"几乎零证据）；给出因果图或等价假设。
4. **策略学习与比较**：分离表示学习、转移/结局模型、策略优化与超参选择；基线应含**观察到的实际实践、简单规则、临床公认标准**，而不只是其他深度 RL 算法；所有经 OPE 比较的策略须在未参与调参的留出轨迹上评估。
5. **评估与不确定性**：尽可能报告**至少两个 OPE 家族**，加置信区间、有效样本量、行为策略距离、超出可靠支持范围决策的比例；估计器分歧本身就是结果，不应挑选最有利的估计。
6. **稳健性、公平与失败分析**：按临床有意义的分组/站点/时段报告并附不确定性；压力测试覆盖奖励变化、未测混杂、数据损坏、容量与转移漂移；记录开发中被否决的策略及其失效边界。
7. **前瞻状态与治理**：标注实际达到的最高阶梯层级；说明覆写机制、事件响应、回滚、再评估触发条件与审批责任。

### 2.4 其他方法学主张

- **外部有效性是策略依赖的**：预测泛化问"模型在新人群中是否仍准确"，策略泛化问"新策略改变动作后所访问状态上的准确性"；行为策略距离不只是统计量，而是"多少干预仍未被检验"的指标。
- **不确定性必须改变行动**：应决定"推荐、推迟、采集信息、收缩动作集还是升级给人类"；一个恰当弃权的策略可以有更低覆盖率但更高临床价值。可逆性决定响应方式（低成本消息可谨慎在线学习，药物/器械需先验证据与密切监督，群体分配对个体可逆却可能累积不公平）。
- **奖励规范是经验性与规范性的双重瓶颈**：死亡率重要但稀疏、住院时长可能奖励过早出院、依从性可能忽略治疗是否有益、吞吐量可能与连续性或公平冲突。复合奖励的权重内嵌价值判断，故**对奖励定义的敏感性应作为主分析而非次要消融**；高风险照护中，硬性临床排除不应仅表示为大负奖励（优化会将其交易掉）。

## 6. 主要结论与发现

- **核心缺口**：策略在历史数据上的高估计回报，只是**早期结果**，而不是"失败的临床试验"；把它描述为临床改善是问题所在。OPE 估计的是"在明示假设下的反事实"，它不测量可用性、依从性、工作流适配或均衡效应。
- **跨域规律（6.1–6.4）**：
  1. **该领域"策略丰富、干预证据贫乏"**：急性照护多在一两个 ICU 库上比较估计回报/动作一致性；mHealth 常有随机化但多测近端行为响应而非持久临床终点；运筹研究可在精细仿真中评估，但转移模型常遗漏组织响应。
  2. **奖励规范是经验性与规范性的双重瓶颈**：对奖励定义的小改动若导致定性不同的策略，说明发现的是**规范问题**而非"选出了赢家"；偏好/语言学习让规范更易表达但不消除规范选择；语言流畅性可能**掩盖**而非解决分歧。
  3. **外部有效性依赖策略本身**：初始迁移良好的策略可能创造新的状态分布，使其表示与转移模型不可靠；行为策略距离越大，未检验的干预部分越多；外部验证应变化的不只是"医院身份"，还包括日历时间、人员配置、临床协议、数据采集系统、资源容量与动作可用性。
  4. **不确定性必须改变行动**：高置信 OPE 与安全策略改进是形式化起点，但其保证仍以所选状态、成本与不确定性模型为条件；单一"安全 RL"标签会抹平"控制的失败是什么、时间尺度多长、谁有权干预"。
- **可迁移与不可迁移**：可迁移的是四条原则（策略比较的可信度取决于支持与因果假设；不确定性应界定部署范围；评估须跨时间与群体追踪结局；干预包含其界面、使用者与运营约束）；不可自动迁移的是具体证据——同一治疗策略换医院可能因文档或人员流程而失败；移动干预可快速随机化而高风险治疗不可；分配策略个体低风险却可能通过反复拒绝服务产生群体层面不公平。**泛化是被检验的问题，不是预训练策略的默认属性**。
- **对未来综述与资助的启示**：未来综述应按应用族、数据来源、因果假设、策略距离、OPE 方法、外部验证、前瞻状态与治理对每项研究编码，从而显示证据在哪里积累、哪里大量论文反复停留在同一早期层级；资助体系应承认各层级各自的严谨性，早期

- **对未来综述与资助的启示（续）**：早期层级（形式化、识别）的严谨性应被承认为**独立的研究贡献**，而不是"尚未做实验"的半成品；同时资助重心需向**前瞻评估与生命周期治理**倾斜，否则领域会持续生产大量停留在第 2–3 级的论文，却永远无法回答"是否真的改善了照护"。作者暗示，当前激励结构（追求高估计回报、偏好新颖算法）与所需的证据结构（累积、跨阶段、可失败）之间存在系统性错配。
- **对"可复现性"的再定义**：在 RL 医疗场景中，复现一个**数字**（回报估计）意义有限；真正需要复现的是**证据链**——相同的形式化假设、相同的识别条件、相同的行为策略信息与相同的评估协议下，结论是否稳定。论文因此把"可复现"从代码层面推进到**假设与治理层面**。

## 7. 论文的主要贡献与创新点

1. **框架性贡献：证据阶梯**。将医疗 RL 的评价问题从"算法/疾病分类"重构为"证据成熟度分级"，为异质文献提供了统一坐标系；其关键设计是**层级不可互相替代**——高层的成功不能回溯性地为低层的假设背书，低层的失败也不能被高层的收益掩盖。
2. **操作性贡献：证据卡**。把抽象的层级要求转化为可填写的报告条目，使"支持范围""行为策略距离""估计器分歧""被否决的策略"等通常被省略的信息成为**标准披露项**。
3. **概念澄清**：
   - 区分**预测泛化**与**策略泛化**，指出外部有效性是策略依赖的；
   - 指出**行为策略距离**是"未被检验的干预量"的度量，而非单纯的技术统计量；
   - 论证**不确定性应改变行动**（推荐/推迟/采集信息/收缩动作集/升级给人），把弃权视为一种正当且有价值的策略输出；
   - 将**奖励规范**定位为经验性与规范性的**双重瓶颈**，主张奖励敏感性分析应上升为主分析。
4. **跨域整合**：把临床治疗、患者端参与、卫生系统运营三类决策族放在同一证据框架下对照，指出它们各自拥有对方缺失的证据优势（临床有意义终点 / 实验变异 / 显式资源约束），为方法迁移提供了方向而非口号。
5. **对评价基础设施的倡议**：主张 benchmark 与排行榜应**分离识别、估计、稳健性与前瞻证据**，并附带行为策略信息、时间与站点划分、缺失机制与临床基线，反对将多维证据坍缩为单一回报数字。

## 8. 局限与批判性讨论

- **框架本身的实证缺位**：证据阶梯与证据卡均为**规范性提议**，论文未提供任何实证检验（如专家间一致性、对既有论文的判别力、对实际部署决策的影响）。因此其"有用性"目前是论证性的，而非被验证的。
- **层级的边界模糊**：真实研究中"识别"与"估计"、"压力测试"与"前瞻评估"常相互纠缠（例如前瞻研究本身也承担识别功能），阶梯的线性外观可能低估迭代与回退的实际形态；论文虽强调"高层依赖但不替代低层"，却未充分讨论**层级间的循环与并行**。
- **规范性主张的不可解性被指出但未解决**：论文正确指出"不存在通用公平度量"、奖励权重内嵌价值判断，但对**如何在多方冲突下达成可操作的规范决策**着墨有限，更多是要求"显式说明"与"报告多重结果"，这属于程序性回应而非实质性方案。
- **对资源与能力约束的低估**：前瞻评估（静默试验、微随机化、受控放量）与生命周期治理（监测、漂移响应、再审计）在真实卫生系统中成本高昂，需要统计、临床、伦理、运营与监管的多方协作；论文对**中小机构或资源匮乏环境如何执行**阶梯缺乏讨论，可能使框架在实践上偏向资源充裕者。
- **文献选择与自引风险**（见第 5 节）：作为单一作者的定向叙述性综述，缺乏系统检索与双人编码，存在选择偏差与议程自我强化的可能。
- **时效性风险**：领域（尤其基础模型、语言化奖励、离线 RL）演进极快，截至 2025 年的归纳可能迅速过时；而框架的价值恰在于其**对技术更替的稳健性**——这一点有待时间检验。

## 9. 对研究与实践的启示

- **对研究者**：
  - 报告策略性能时，必须同时报告**支持范围**（多少决策落在可靠支持内）、**行为策略距离**与**有效样本量**；
  - 至少使用**两个 OPE 家族**并报告分歧，禁止事后挑选最有利估计；
  - 基线应包含**实际临床实践、简单规则与公认标准**，而非仅与其他深度 RL 对比；
  - 所有经 OPE 比较的策略须在**未参与调参的留出轨迹**上评估；
  - 记录**被否决的策略及其失效边界**，把负面结果视为可累积的证据而非失败。
- **对临床与运营部署方**：
  - 明确系统的**建议性/自主性边界**、覆写机制、回滚条件与责任人；
  - 区分"记录的医嘱"与"实际给予的治疗"，避免用文档行为代替真实暴露；
  - 关注**人-AI 联合策略**：自动化偏见与警报疲劳会实质改变被评估的策略本身；
  - 分配类系统需追踪**群体层面的累积效应**，因为个体层面的低风险可能通过反复拒绝服务转化为结构性不公平。
- **对资助与监管机构**：
  - 承认**各层级各自的严谨性标准**，为形式化、识别、前瞻与治理阶段分别设立可评审的资助类别；
  - 要求并支持**前瞻评估与部署后监测**，而非仅资助算法开发；
  - 推动共享数据基础设施，纳入行为策略信息、时间/站点划分、缺失机制与亚组标签。

## 10. 总结性评价

本文的核心洞察简洁而有力：**医疗 RL 的瓶颈不在优化，而在证据**。它把"高估计回报"从结论降格为起点，把"策略"重新理解为"嵌入不断变化的社会技术系统中的干预"，并据此提出证据阶梯与证据卡作为跨阶段、可累积、可失败的评估结构。其方法论立场（估计器分歧应作为结果、不确定性应改变行动、奖励敏感性应为主分析、外部有效性是策略依赖的）具有明确的自我约束性，对当前以排行榜和单一回报为中心的研究生态构成有力批评。

同时，作为一篇单作者的定向叙述性综述，它**提出了框架但未验证框架**，在层级边界、规范冲突的可操作解决、资源约束与检索系统性方面留有明显空间。其最持久的贡献或许不是某条具体建议，而是把领域的关键问题从"哪种算法更好"重写为——**"我们究竟需要什么样的证据，才敢把这个策略放进真实的照护流程？"**
