## 摘要
在纵向患者轨迹上训练的电子健康记录（EHR）基础模型已在多种临床预测任务中展现出强大性能。然而，其临床推理能力仍受限于在有限且不完整的EHR数据上的下一词元预测。为解决这一问题，我们提出了一种强化学习（RL）微调框架，将EHR基础模型视为患者轨迹上的生成式策略。我们将常见的临床预测问题（如再入院）形式化为事件条件化、时间窗口化的推理任务。随后，我们设计了时间感知、对展开（rollout）敏感的奖励，以考虑有限的展开长度和时间上不确定的结果。我们发现，RL微调持续优于预训练骨干模型和强基线。值得注意的是，它使较小模型在数据受限场景下超越更大的预训练模型，并诱导任务间的正向迁移。进一步分析表明，经RL微调的模型生成的轨迹与真实标签具有更强的结构和语义对齐，并具有更高的下游效用。

## Abstract
Electronic health record (EHR) foundation models trained on longitudinal patient trajectories have demonstrated strong performance across diverse clinical prediction tasks. However, their clinical reasoning capabilities remain constrained by next-token prediction on limited and incomplete EHR data. To address this, we propose a reinforcement learning (RL) fine-tuning framework that treats EHR foundation models as generative policies over patient trajectories. We formulate common clinical prediction problems (e.g., hospital readmission) as event-conditioned, time-windowed reasoning tasks. We then design time-aware, rollout-sensitive rewards to account for finite rollout lengths and temporally inconclusive outcomes. We find that RL fine-tuning consistently improves over pre-trained backbones and strong baselines. Notably, it enables smaller models to surpass larger pre-trained models in data-limited regimes and induces positive transfer across tasks. Further analysis shows that RL fine-tuned models generate trajectories with stronger structural and semantic alignment to ground truth and greater downstream utility.

# 论文总结：面向 EHR 基础模型临床推理的患者轨迹强化学习

## 1. 核心问题与研究背景

- **背景**：大规模 EHR 数据集（MIMIC-III/IV）催生了 EHR 基础模型（如 ETHOS），其做法是把患者历史编码为按时间排序的异构临床事件 token 序列，用 Transformer 做下一词元（next-token）自回归预训练，在多种临床预测任务上表现良好。
- **核心问题**：
  - EHR 基础模型的临床推理能力受限于**有限且不完整的 EHR 数据上的下一词元预测**；
  - 在固定临床数据规模下，**模型扩展（scaling）收益递减**；
  - 下一词元预测对**长时程推理**任务效率低；
  - 真实 EHR 时间线**缺失、不规则**，破坏时间依赖关系，难以学到有临床意义的动态。
- **整体含义**：需要超越"下一词元预测"的**后训练（post-training）策略**。作者提出把预训练 EHR 基础模型视为**患者轨迹上的生成式策略（generative policy）**，用可验证的、任务特定的奖励进行强化学习微调，直接优化轨迹级临床推理。

## 2. 方法论

### 2.1 核心思想
- 将常见临床预测问题（再入院、ICU 再入院、住院死亡）形式化为**事件条件化、时间窗口化的推理任务**；
- 通过模型 rollout（生成未来患者轨迹）并聚合结果来做预测，用 RL 优化"生成轨迹的临床正确性"。

### 2.2 关键技术细节
- **预训练形式化**：轨迹 τ = (x₁,…,x_|τ|)，由医学事件 token、时间 token（事件间间隔）与辅助/静态上下文 token 组成；预训练最小化负对数似然 ℓ_PT。
- **RL 微调**：把模型参数化为随机策略 π_θ，rollout τ̂ 为在观测前缀条件下的未来轨迹生成，目标是最大化 E_τ̂∼π_θ[R(τ̂)]。采用 **GRPO**（带裁剪的代理损失，优势按同一上下文内 rollout 组归一化）与 **DAPO**（非对称裁剪 + 动态采样）。
- **任务定义三元组**：(anchor 事件 x, 未来目标事件 x*, 时间窗 W)。
  - 30 天再入院：anchor = 住院出院，检查 30 天内是否有新入院；
  - 2 年 ICU 再入院：anchor = ICU 出院，检查 2 年内是否再次 ICU 入院；
  - 2 年住院死亡：anchor = 入院，检查 2 年内出院前是否死亡。
- **核心难点**：临床任务定义在**真实时间窗 W** 上，而 EHR 基础模型受**有限 rollout token 长度 H** 约束。为此提出"时间感知、rollout 敏感"框架，分两级处理：
  1. **训练数据过滤**：定义 t、t*（x* 首次出现位置，∞ 表示未出现）、w（W 内最后观测 token 的索引）。保留条件为 `min(t*, t+w) ≤ min(t+H, |τ|)`。被过滤的两类情形：
     - **Rollout overflow**：目标事件或时间窗边界超出 H（不希望模型学会跳过中间事件）；
     - **Incomplete follow-up**：观测轨迹在到达 x* 或 W 前终止，证据不足。
     保留样本的标签为 `y = 1[t* ≤ t+w]`。
  2. **Rollout 奖励分配**：从 anchor 前缀采样多条 ≤H token 的 rollout。若 rollout 到达 x* 或完整时间窗 W，则**合格（qualified）**；否则视为**不确定（inconclusive）**，**既不给奖励也不给惩罚，并排除在优势归一化与策略更新之外**（避免强迫模型在固定预算内下结论、避免跳过中间事件、避免扭曲预训练分布）。合格 rollout 仅在 W 内评估，`ŷ = 1[t̂* ≤ t+ŵ]`，奖励为可验证的二值 `R(τ̂) = 1[ŷ = y]`。

### 2.3 实现细节
- 使用 **VERL** 框架；rollout 遇到目标 token x* 或到达时间窗 W 即截断，避免在评估窗口外的无关 token 上更新；
- 学习率在 {5e-6, 1e-5, 5e-5} 中搜索，最终取 **1e-5**；训练 **1 个 epoch**，每例 **8 条 rollout**，pre-anchor 最大长度 **2048 token**，最大 rollout 长度 **2048 token**；
- 测试时每例采样 **20 条随机 rollout**，以正预测比例作为标量分数计算 AUROC/AUPRC。

## 3. 实验设计

- **数据集**：MIMIC-IV v2.2，沿用 Renc et al. (2024) 的数据构建与训练/验证/测试划分。为防止 reward hacking，对每个任务下采样负例使标签平衡。
  - 训练集规模：30 天再入院 **140,466**；2 年 ICU 再入院 **9,390**；2 年住院死亡 **10,670**；
  - 多任务 RL 中，两个小任务被上采样到与 30 天再入院同规模，避免最大任务主导梯度。
- **Backbone**：ETHOS EHR 基础模型，**9M 与 56M** 两个规模（上下文窗口 4096 token）。
- **对比方法（Benchmark 组合）**：
  - ETHOS-PT：自回归预训练模型；
  - ETHOS-SFT：监督微调（输入 anchor 前缀，目标为真实 post-anchor 轨迹）；
  - ETHOS-Logistic：用 anchor token 表示训练逻辑回归（判别式基线）；
  - ETHOS-GRPO / ETHOS-DAPO（本文方法）；
  - 任务专用 9M Transformer Encoder（端到端训练，仅 30 天再入院）；
  - LLM 基线：MedReason-8B、MedGemma-27B、Gemini-3.7-Flash（高思考强度），把轨迹转成英文 prompt，评测 zero-shot 与 3-shot ICL。
- **评价指标**：AUROC、AUPRC；另评估校准（ECE）、90% 召回下的假阳性率、配对显著性检验。
- **分析类实验**：
  - 轨迹对齐：编辑距离、bigram overlap（结构）；加权 Jaccard、余弦相似度（语义），并映射到临床事件类型空间复算；
  - 下游效用：用生成轨迹的 token 频次向量训练决策树（最大深度 10，min_samples_split/leaf = 100），在 30 天再入院上评估；

## 6. 主要结论与发现

- **RL 后训练显著优于同源预训练与监督微调**：在 30 天再入院任务上，ETHOS-GRPO 与 ETHOS-DAPO 在 AUROC/AUPRC 上均超过 ETHOS-PT、ETHOS-SFT 与 ETHOS-Logistic，且配对检验显著（GRPO p=0.014，DAPO p=0.033），说明"轨迹级可验证奖励"比"下一词元模仿"更贴合临床推理目标。
- **多任务 RL 具有正向迁移与递进效应**：随训练任务数增加，三个评估任务的性能整体呈上升趋势，表明不同临床终点共享可复用的轨迹推理能力，而非彼此干扰。
- **生成轨迹在结构上与真实轨迹更接近**：编辑距离、bigram overlap、加权 Jaccard 与余弦相似度四项指标上，RL 微调模型均显著优于预训练/SFT 基线（p<0.0001），且映射回临床事件类型空间后结论保持，说明改进不只体现在表层 token 分布。
- **生成轨迹具备下游可用性**：以 RL 生成轨迹的 token 频次向量训练决策树，在 30 天再入院上取得优于基线轨迹的 AUROC/AUPRC，说明模型输出保留了可被独立模型利用的临床信号，而非仅拟合奖励。
- **奖励设计的关键性**：把 inconclusive rollout 纳入训练（给予惩罚或参与优势归一化）会损害性能；在不平衡数据上使用非对称奖励亦不如类平衡采样 + 对称二值奖励，验证了"不确定即弃权"这一设计的必要性。
- **Rollout 数量与性能正相关但边际递减**：从 2 条增至 20 条时性能提升，约在 8–12 条后趋缓，提示测试时采样是一种可用但成本受限的推理增强手段。
- **LLM 基线整体落后**：MedReason-8B、MedGemma-27B、Gemini-3.7-Flash 在 zero-shot 与 3-shot 下均未超过领域专用 EHR 基础模型 + RL，说明通用医学 LLM 在长时程、时间窗精确的 EHR 推理上仍有明显差距。

## 7. 贡献与创新点

1. **问题重构**：把 EHR 基础模型的临床预测从"判别式分类"重构为"患者轨迹上的生成式策略优化"，用可验证奖励直接优化轨迹级正确性。
2. **时间感知的 rollout 敏感框架**：显式区分"合格"与"不确定"rollout，通过训练数据过滤（overflow / incomplete follow-up）与奖励分配两级机制，缓解真实时间窗 W 与固定 token 预算 H 之间的根本矛盾。
3. **可验证奖励的临床落地**：将再入院、ICU 再入院、死亡三个终点统一为 (anchor, 目标事件, 时间窗) 三元组，使奖励可自动判定、无需人工标注偏好。
4. **系统的实证与诊断**：不仅报告 AUROC/AUPRC，还从轨迹对齐、下游效用、校准、消融、rollout 数量等多角度刻画 RL 带来的变化，增强了结论的可解释性。

## 8. 局限性

- **数据与任务的窄覆盖**：仅基于 MIMIC-IV 单一中心数据，三个任务均为粗粒度二值终点，未涉及治疗决策、药物推荐、多步干预等更复杂的临床推理。
- **评估范式依赖采样**：测试时以 20 条 rollout 的正例比例作为分数，推理成本随采样数线性增长，实际部署的时延与算力代价未讨论。
- **时间建模仍受 token 预算限制**：H=2048 的 rollout 上限意味着长时程事件（如 2 年窗口）必须依赖截断与过滤，可能系统性丢弃部分有效样本，带来选择偏差。
- **基线强度不均衡**：LLM 基线未做领域适配微调，判别式基线仅在单任务上训练，跨方法比较的公平性存在改进空间。
- **可复现性与统计严谨性**：未报告随机种子方差、置信区间与 56M 模型的计算成本，超参搜索范围也较窄。
- **奖励 hacking 风险仅部分缓解**：虽通过类平衡与二值奖励降低风险，但未系统分析模型是否学会利用时间 token 或静态上下文 token 走捷径。

## 9. 启示与展望

- **范式层面**：该工作为 EHR 基础模型指出了一条"预训练 → 可验证奖励 RL 后训练"的可行路径，与 NLP 领域的 RLVR 思路一致，提示临床预测任务天然适合可自动判定的奖励设计。
- **方法层面**：inconclusive rollout 的处理方式具有普适价值——在证据不足时让模型"弃权"而非被迫作答，既符合临床安全原则，也避免了分布外监督信号。
- **未来方向**：扩展到更细粒度的临床终点与多步干预决策；引入过程奖励或中间事件对齐奖励；在 H 与时间窗之间做自适应预算分配；在多家机构数据上验证跨中心泛化；与经过领域微调的开源医学 LLM 做更严格的对比。

## 10. 总体评价

论文选题切中 EHR 基础模型"会预测、不会推理"的痛点，方法论上把生成式策略、可验证奖励与时间窗约束有机结合，并针对真实时间窗与 token 预算的错配提出了清晰且可实现的工程化方案。实验设计覆盖面较广，主结论有配对检验支撑，轨迹对齐与下游效用分析提升了说服力。主要短板在于数据集单一、任务粒度粗、统计报告不够完整，以及基线调优的公平性有待加强。总体而言，这是一项方法上有新意、工程上可落地、结论方向可信但需更多外部验证的研究。
