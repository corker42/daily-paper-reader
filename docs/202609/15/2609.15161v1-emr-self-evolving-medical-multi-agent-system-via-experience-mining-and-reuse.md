## Abstract
Large language model (LLM) driven multi-agent systems have shown promise in complex clinical reasoning, yet existing approaches rely on static strategies and lack persistent clinical memory, preventing self-evolving from prior diagnostic successes and failures. We present EMR, a self-evolving medical multi-agent system via Experience Mining and Reuse. EMR introduces a hierarchical clinical experience library that organizes accumulated knowledge into three levels: clinical principles, diagnostic patterns, and representative cases. During inference, EMR emulates multidisciplinary consultation: a planner agent coordinates domain-specific department agents for specialized reasoning, while a summary agent synthesizes their analyses into a final decision. Critically, EMR automatically extracts correct diagnostic insights and failure-related warnings from multi-agent reasoning trajectories, incrementally updating the experience library to guide future cases. Experiments on medical reasoning benchmarks demonstrate that EMR consistently outperforms state-of-the-art medical multi-agent baselines. ## 一、核心问题与整体含义

- **研究背景**：LLM 驱动的多智能体系统在复杂临床推理（多症状表现、鉴别诊断、跨科室会诊）中展现潜力，但现有系统存在两大根本缺陷。
- **核心问题**：
  - **静态性**：依赖固定推理策略，面对复杂或未见病例时反复出现同类诊断错误。
  - **无记忆性**：将每个任务视为孤立实例，无法从既往成功经验中学习、也无法规避已犯过的错误。
- **关键论断**：缺失的组件是**显式且持久化的经验抽象**——不应仅在孤立层面演化提示词或工作流，而应从多智能体自身的推理轨迹中提炼可迁移、可扩展、模型无关的复用知识。
- **整体含义**：EMR 提出一种无需修改模型参数、通过"经验挖掘—分层存储—检索复用"闭环实现自演化的医疗多智能体框架，为持续进化的临床推理系统提供可扩展、可解释的路径。

## 二、方法论

### 2.1 核心思想
将多智能体协作推理过程显式记录为结构化轨迹，从中挖掘"黄金经验"（成功）与"警示经验"（失败），按**原则—模式—案例**三层组织为经验库，在推理时动态检索注入各智能体，实现参数不变的持续进化。

### 2.2 多智能体医疗系统（模拟多学科会诊）
- **规划智能体（Planner）**：识别问题级领域集合 $D_q$ 与选项级领域集合 $D_o$，将推理空间分解为领域子问题，并结合检索经验避免既往领域分配错误。
- **科室智能体（Department Agents）**：对每个领域 $d$ 生成专门分析 $a_d = \text{LLM}(q, O, d, E_r \mid r_d, \pi_d)$，汇总为分析集合 $A$。
- **总结智能体（Summary Agent）**：综合跨科室分析与检索经验，进行反思性推理，输出最终预测 $\hat{y}$ 与综合分析 $a_{sum}$，可解决矛盾并纠正局部错误。

### 2.3 经验挖掘
- **轨迹生成**：完整记录 $\tau = (q, O, D_q, D_o, A, a_{sum}, \hat{y})$，与标准答案 $y$ 对比判定成功/失败。
- **经验收集与分类**：
  - **黄金经验**：来自成功轨迹，捕捉有效推理策略、诊断原则与验证过的决策模式。
  - **警示经验**：来自失败轨迹，总结失败原因、误导性线索与反复出现的错误模式。
  - 由 collector 角色按提示 $\pi_c$ 抽取自然语言经验条目 $\epsilon$。

### 2.4 经验复用
- **三层经验库**：$L = \{L_{principle}, L_{pattern}, L_{case}\}$，分别存储抽象诊断规则、可复用推理结构与具体临床案例。
- **更新机制**：
  - 检索相关经验 $R$，计算语义相似度 $\text{Sim}(\epsilon, R)$（余弦相似度）。
  - 若 $\text{Sim} < \theta$（默认 0.85），直接加入；否则由 LLM 判断合并为更紧凑表示或丢弃冗余项。
- **检索机制**：按"先原则→再模式→后案例"的层次化顺序检索 $k$（默认 3）条经验，注入规划、科室与总结智能体，作为外部模型无关知识源。

## 六、主要结论与发现

- **主结果**：EMR 在所有 LLM 与数据集上一致超越基线。Qwen3-8B 上平均准确率从 MDAgents 的 77.8 提升至 81.1；GPT-4o 上达到 93.9（MedQA 96.8，MMLU-Pro 生物学 93.1）。
- **经验是核心增益来源**：移除经验模块导致 6.7% 下降，回落至静态系统水平；经验贡献最大。
- **经验层级贡献排序**：原则级 > 模式级 > 案例级（移除分别下降 4.6%、2.5%、1.2%），原则级为跨场景迁移的核心。
- **警示经验不可或缺**：仅用黄金经验下降 2.6%，警示经验作为"护栏"帮助规避既往错误。
- **双向迁移性**：强模型（GPT-4o、DeepSeek-V3）挖掘的经验可显著提升弱模型；弱模型经验亦能反哺强模型。跨数据集迁移也持续正向。
- **架构无关性**：将 EMR 集成到 MDAgents、RECONCILE 分别带来 2.7、2.4 分提升。
- **效率优势**：EMR 每样本 1200 token、15 秒，优于 MDAgents（1900 token、23 秒）与 RECONCILE（2500 token、33 秒）。
- **失败模式归纳**：参数化知识过度依赖、医学概念混淆、表层因果推理、多智能体集体幻觉。
- **鲁棒性**：仅保留 10–20% 经验或注入 20–40% 噪声时，性能仍显著高于无经验基线。

## 七、优点

- **方法设计亮点**：

- **方法设计亮点**：
  - 将“经验”从提示词工程或工作流模板中抽象出来，提升为独立、可检索、可合并、可迁移的外部知识层，使多智能体系统无需参数更新即可持续进化。
  - 采用“原则—模式—案例”三层经验库，兼顾抽象规则的可迁移性与具体案例的可操作性，避免单一粒度经验导致的过拟合或泛化不足。
  - 同时挖掘黄金经验与警示经验，形成“正向策略 + 负向护栏”的双通道学习机制，更贴近临床推理中“既要遵循指南，也要避免误诊陷阱”的实际需求。
  - 经验注入覆盖规划、科室、总结三类智能体，使经验在推理全流程中发挥作用，而非仅在最终回答阶段进行事后修正。
  - 设计基于语义相似度的经验合并与去重机制，在一定程度上缓解经验库无限膨胀带来的检索噪声与成本问题。
  - 整体框架模型无关、架构无关，可作为插件集成到 MedAgents、MDAgents、RECONCILE 等既有系统中，具有较好的工程可移植性。

## 八、局限与不足

- **经验挖掘依赖标注数据与初始成功/失败信号**：框架需要标准答案来判定轨迹成败，在真实临床场景中，金标准往往滞后、稀缺或存在争议，冷启动和持续监督成本较高。
- **检索机制仍以语义相似度为主**：仅依赖嵌入余弦相似度与固定阈值，可能漏检“表面不相似但临床逻辑相关”的经验，也可能引入“语义相似但情境不适用”的干扰经验。
- **经验库长期演化机制不完整**：论文验证了经验库规模增长与性能关系，但未充分讨论经验冲突、过时知识、错误经验固化以及遗忘/淘汰策略，长期运行下的稳定性和安全性仍需验证。
- **评估指标较为单一**：主实验以准确率为主，缺少对推理链正确性、可解释性、校准度、临床安全性、错误严重程度等维度的系统评估。
- **数据集与样本规模限制**：部分数据集仅使用数百样本进行挖掘与测试，MMLU-Pro 子集规模较小，统计波动和过拟合风险不可忽视；且数据多来自考试型问答，与真实电子病历、多轮问诊、跨模态检查结果存在分布差异。
- **硬件与成本披露不完整**：论文给出 API 成本与推理时间，但未披露 GPU 型号、数量、显存、嵌入模型部署成本及总体碳足迹，复现与规模化部署的经济性评估不够充分。
- **安全、伦理与责任边界讨论不足**：作为医疗决策支持系统，经验库若包含偏见、错误或过时知识，可能被放大；论文未深入讨论隐私保护、数据脱敏、临床责任归属与监管合规问题。
- **多智能体通信开销与错误传播**：尽管 EMR 在 token 与延迟上优于部分基线，但多科室智能体并行生成与经验检索仍带来额外开销；局部错误若被总结智能体误信，仍可能形成集体幻觉。

- **向真实临床工作流延伸**：后续工作可将 EMR 与电子病历、多模态检查、指南知识库、临床路径结合，并在多轮问诊、跨科室会诊、罕见病诊断中验证。
- **人机协同与可解释性增强**：经验库天然提供自然语言解释，未来可让医生审查、编辑、标注经验，形成“医生反馈—经验更新—系统改进”的持续协同闭环。
- **安全护栏与监管适配**：需要建立经验库版本控制、偏差检测、不确定性估计与拒答机制，以满足医疗 AI 的合规与安全要求。

## 十、总体评价

- **贡献定位**：EMR 的核心贡献不在于提出新的基座模型或复杂网络结构，而在于将“经验抽象与复用”系统化地引入医疗多智能体推理，形成一套参数不变、模型无关、可解释的自演化框架。
- **创新程度**：三层经验库、黄金/警示双通道挖掘、层次化检索与合并机制具有较强的新颖性和组合创新价值，尤其契合医疗推理中“原则指导 + 案例参照 + 错误规避”的认知特点。
- **实验强度**：主实验、消融、迁移、鲁棒性、效率与泛化性实验较为完整，结论一致性较高；但部分子集样本量有限，真实临床外部效度仍需进一步验证。
- **实用价值**：对希望在不微调模型的前提下提升医疗多智能体系统可靠性的研究者和工程团队具有直接参考意义，也可作为经验驱动智能体在垂直领域落地的范式样本。
- **总体判断**：EMR 是一篇问题意识清晰、方法设计巧妙、实验覆盖较广的医疗多智能体研究。它有力证明了“显式经验层”是当前 LLM 医疗推理系统缺失的关键组件，但在长期演化、安全治理与真实临床验证方面仍留有较大探索空间。
