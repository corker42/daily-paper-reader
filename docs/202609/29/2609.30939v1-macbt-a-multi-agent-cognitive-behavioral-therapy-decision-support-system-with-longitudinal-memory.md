## 摘要
认知行为疗法（CBT）是循证一线抑郁症治疗方法，但其推广规模受限于临床医生在治疗前准备、治疗后记录以及纵向认知病理追踪上所花费的时间。我们提出了一种面向临床医生的AI决策支持系统，它将多智能体CBT框架（MACBT）与CBT专用的纵向记忆模块（CD Memory）相结合。MACBT将CBT五阶段工作流程（评估、苏格拉底式提问、认知重构、行为实验和治疗监测）编码为五个协作智能体。CD Memory跨会话追踪认知扭曲类型、频率、严重程度和重构效果，以生成治疗前病理报告和干预优先级建议。我们通过双角色大语言模型模拟构建中文CBT对话语料库，并采用监督微调和直接偏好优化训练Qwen3-14B基座模型。使用GPT-4作为评判者的评估显示，MACBT在专业性（2.62）和临床真实性（2.25）上优于MeChat、SoulChat、PsyChat和CPsyCounX。完整的记忆增强系统进一步将会话质量提高12.6%，并在跨会话连续性、干预进展和个性化方面取得2.29的纵向平均值。

## Abstract
Cognitive behavioral therapy (CBT) is an evidence-based first-line treatment for depression, yet its scale is constrained by the time clinicians spend on pre-session preparation, post-session documentation, and longitudinal cognitive-pathology tracking. We present a clinician-facing AI decision-support system that combines a multi-agent CBT framework (MACBT) with a CBT-specific longitudinal memory module (CD Memory). MACBT encodes the five-stage CBT workflow (assessment, Socratic questioning, cognitive restructuring, behavioral experiments, and treatment monitoring) into five collaborative agents. CD Memory tracks cognitive-distortion type, frequency, severity, and restructuring efficacy across sessions to generate pre-session pathology reports and intervention-priority recommendations. We construct a Chinese CBT dialogue corpus via dual-role large language model simulation and train a Qwen3-14B backbone with supervised fine-tuning and direct preference optimization. Evaluation with GPT-4 judges shows MACBT outperforms MeChat, SoulChat, PsyChat, and CPsyCounX in professionalism (2.62) and clinical authenticity (2.25). The full memory-augmented system further improves session quality by 12.6% and achieves a longitudinal mean of 2.29 on cross-session continuity, intervention progression, and personalization.

## 一、核心问题与整体含义（研究动机与背景）

- **临床痛点**：CBT 是抑郁症循证一线疗法，但合格治疗师稀缺且分布不均；完整 CBT 疗程通常需 8–20 次会谈，临床医生面临三重结构性负担：
  - **会前负担**：回顾历史记录、评估当前认知状态、识别未解决问题；
  - **会后负担**：手工整理记录、布置作业、追踪依从性；
  - **纵向负担**：跨疗程追踪患者认知病理演变并动态调整方案。
- **量化负担**：管理约 20 名活跃患者的医生，仅会前回顾与会后记录就可能每患者耗费 30–45 分钟。
- **现有方案不足**：
  - Woebot、Wysa 等数字 CBT 系统为规则化、面向患者的预设决策树交互，无法适应患者认知状态演变；
  - MeChat、SoulChat、CPsyCoun 等 LLM 系统提升共情与专业性，但多为面向患者的单会话对话生成器；
  - MAGI 等多智能体框架面向诊断访谈，未覆盖 CBT 序贯治疗阶段；
  - MemoryBank 等通用长期记忆缺乏 CBT 特定构念（如认知扭曲类型、严重度、重构效果）。
- **研究定位**：提出面向临床医生的决策支持系统，将 CBT 治疗逻辑、多智能体推理与跨会话认知扭曲记忆整合，目标不是替代医生，而是提升现有医生生产力与一致性。

## 二、方法论

### 2.1 核心思想
- **MACBT**：将 CBT 五阶段工作流显式编码为五个协作智能体，共享工作记忆，由评估导航器统一调度。
- **CD Memory**：CBT 专用的纵向认知扭曲记忆，跨会话记录扭曲类型、频率、严重度与重构效果，生成会前病理报告与干预优先级建议。

### 2.2 中文 CBT 对话语料构建
- **数据来源**：3,134 份匿名心理咨询报告，提取结构化患者画像（诊断、核心症状、主要问题、主诉、情绪触发、咨询目标）。
- **双角色 LLM 模拟**：
  - 患者智能体仅掌握自身画像，不具备完整对话历史，逐步披露信息；
  - 咨询师智能体受 CBT 五阶段约束：评估、苏格拉底式提问、认知重构、行为实验、巩固。
- **质量约束**：咨询师回复限制在 40 个中文字符以内、避免编号列表、最多一个问题、使用会话式而非说教式语言。
- **终止条件**：患者识别至少一个核心扭曲、建立功能性替代想法、同意行为实验或表达结束意愿；否则 50 轮停止。
- **产出**：过滤后获得 2,000 段多轮对话，约 68,000 条监督微调样本。

### 2.3 模型训练
- **基座**：Qwen3-14B，全参数微调 2 个 epoch（学习率 10⁻⁵，余弦调度，16-bit 精度）。
- **偏好对齐**：DPO，使用 1,347 对偏好数据；每上下文采样 4 个候选回复，按全面性、专业性、真实性、安全性评分，取最高与最低分构成偏好对。

### 2.4 五智能体架构
- **评估导航器**：维护 CBT 阶段结构，决定阶段转换时机。
- **苏格拉底式提问智能体**：生成澄清、假设检验、证据检验、换位思考类问题。
- **认知重构智能体**：识别十类认知扭曲，匹配技术（如全或无思维用连续谱、过度概括用反例、灾难化用概率估计）。
- **行为实验智能体**：设计 SMART 行为实验并追踪执行。
- **治疗监测智能体**：评估会话进展，生成结构化临床报告。
- **共享工作记忆**：存储当前阶段、已识别扭曲、干预历史，支撑各智能体决策。

### 2.5 纵向记忆系统（CD Memory）
- **双环结构**：
  - **会话内环**：Basic Memory 存储核心信念、情绪触发、重大生活事件、行为模式等提炼洞察；CD Memory 指导实时对话。
  - **会话间环**：治疗监测智能体评估扭曲改善、技术效果、行为实验完成度，更新 CD Memory 并生成下一会话治疗计划。
- **CD Memory 记录内容**：每次检测到的认知扭曲类型、触发话语、1–5 严重度评分、重构效果历史。
- **干预优先级公式**：
  - \( P = \alpha r + \beta f + \gamma s \)
  - 其中 \( r \) 为归一化近期性，\( f \) 为频率，\( s \) 为严重度，\( \alpha, \beta, \gamma \) 为权重；优先级最高的扭曲成为当次会话主要干预目标。
- **技术效果记录**：以结构化元组（扭曲类型、技术、效果分、会话 ID）存储，构建患者特异性“技术–反应映射”。
- **动态提示生成**：每轮由静态提示（CBT 角色与安全约束）与动态提示（优先扭曲及背景、推荐/避免的重构技术、当前 CBT 阶段）组装而成。

## 六、主要结论与发现

- **单会话性能**：MACBT 在专业性（2.62）和临床真实性（2.25）上优于 MeChat、SoulChat、PsyChat、CPsyCounX，总体均值最高（1.83）。全面性（1.44）略低于 CPsyCounX（1.56），原因是导航器聚焦当前 CBT 阶段的深度优先策略，而非罗列多主题。
- **训练策略**：CBT 专用 SFT 显著优于通用心理健康 SFT（专业性 2.48 vs 2.08）；DPO 进一步提升专业性 +0.14、真实性 +0.27，且真实性提升最大，表明 DPO 能抑制泛化、过度顺从的回复。
- **微调策略**：全参数微调优于 LoRA；LoRA rank=64 专业性接近（2.38 vs 2.48），但整体均值仍略逊（注：表格中均值存在细微出入）。
- **数据规模**：专业性随数据量单调提升（500→2,000 段：1.89→2.48），全面性与真实性在 1,500 段后饱和。
- **纵向记忆**：
  - 完整记忆增强系统会话质量提升 12.6%（1.83→2.06）；
  - 纵向均值 2.29，其中跨会话连续性 2.38、干预进展 2.27、个性化 2.21；
  - 单会话 CD Memory 纵向均值仅 1.72，通用跨会话摘要 1.48，证明跨会话持久化与结构化扭曲级记忆的关键作用；
  - 移除效果记录主要损害个性化（2.21→1.81）；移除会话间规划主要损害干预进展（2.27→1.74）；移除跨会话持久化则三项指标全面下降。
- **总体判断**：对于纵向 CBT，结构化记忆的重要性可能与高质量对话生成相当。

## 七、优点

- **临床流程编码明确**：将 CBT 五阶段显式映射为五个协作智能体，阶段约束可防止治疗阶段跳跃，提升专业性与治疗保真度。
- **双角色语料构建设计巧妙**：通过信息不对称模拟患者与咨询师，避免“全知改写”导致的治疗师主导独白，提升对话探索性与情境响应性。
- **CD Memory 构念具体**：不仅记录“说了什么”，还记录扭曲类型、严重度、技术效果，形成患者特异性技术–反应映射，支持精准干预规划。
- **动态提示机制**：将优先扭曲、推荐/避免技术、当前阶段组装为每轮动态提示，兼顾上下文窗口压力与干预相关性。
- **消融实验较系统**：覆盖训练策略、微调方式、数据规模、记忆组件，结论有较强内部支撑。
- **安全设计分层**：内容层禁止诊断与用药建议、工作流层可终止或转交、人类监督层定位为医生草稿建议。
